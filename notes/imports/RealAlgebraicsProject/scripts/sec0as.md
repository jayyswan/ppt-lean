**S68.1 (node-line residuals, over any field).** [numerical] (`node68.py 40 1`: 40 random nodes, split and non-split; max residual 1.6·10⁻¹⁴; every residual point has Jacobian rank 3 and 10 distinct y_i²) + *unchecked* (short algebra, complete).
- Let F be a field of characteristic 0 and A an étale F-algebra of degree 10 containing ν with ν² = d ∈ F^×, Tr ν = 0, ν ∉ F (a projective node of X_A and V_A defined over F; over F̄, ν = √d·(1_S − 1_{S^c}) with |S| = 5). For v ∈ **Y_ν = {Tr v = Tr(νv²) = Tr v³ = 0} ⊂ P(A/⟨ν⟩)** (a (2,3) complete intersection 5-fold in P⁷) the line ν + κv lies in X_A, and Tr(ν + κv)⁵ = 5κ⁴·Tr(νv⁴) + κ⁵·Tr(v⁵), because ν² = d kills Tr ν⁵, Tr(ν⁴v), Tr(ν³v²), Tr(ν²v³). Hence **y = Tr(v⁵)·ν − 5Tr(νv⁴)·v ∈ V_A(F)** for every v ∈ Y_ν(F) with Tr v⁵ ≠ 0, smooth and a generator for general v. This is S67.3(d) over the base field, for split nodes (A = A1 × A2 of degrees 5 + 5, ν = (1, −1)) and non-split ones (A ⊇ F(√d), ν = √d).
- **The quintic disappears:** when A has an F-rational node, V_A(F) ≠ ∅ follows from a suitable F-point of the quadric-cubic Y_ν. Over ℚ, primitive A have no rational node (S65.1), so this is a tool for local fields, p-fields and imprimitive algebras, not a ℚ-mechanism for the open cases.

**S68.2 (local consequences).** *unchecked* (short) + exact enumeration (`parts68.py`).

**S68.3 (the transfer as a relative Hermite–Joubert problem; reduction).** *unchecked* (short; complete given Hooley IV).
- Let B = A⁸ be the space of monic decics f = x¹⁰ + e2x⁸ + e4x⁶ + e5x⁵ + … + e10 (e1 = e3 = 0, i.e. p1 = p3 = 0), F = ℚ(B), E = F[x]/(f) the generic algebra with its tautological point θ ∈ X_E(F). **Relative Hermite–Joubert problem RHJ_10:** does E contain a with Tr a = Tr a³ = Tr a⁵ = 0 and F[a] = E? Equivalently: can the generic decic with e1 = e3 = 0 be Tschirnhaus-transformed over its own coefficient field into the row-B5 shape E(w²) + w(αw² + β) (e1 = e3 = e5 = 0)?
- **Reduction:** if RHJ_10 holds, then for every degree-10 étale ℚ-algebra A whose ramified completions carry smooth points of X_A, V_A(ℚ) contains generators of A. Sketch: a solution is a covariant a = Φ(θ) = g(θ)/f'(θ), g ∈ F[x] of degree ≤ 8 (Euler: Tr(θ^j/f'(θ)) = 0 for j ≤ 8, so Tr a = 0 is automatic); its indeterminacy and non-generator loci pull back to S_10-invariant proper closed subsets of X̄ and hence of every twist X_A; X_A(ℚ) is nonempty (Hooley IV, S67.1–S67.2), consists of smooth points for primitive A, and is Zariski dense (a cubic hypersurface of dimension ≥ 2 with a smooth ℚ-point is unirational; *unchecked* for the nodal case); so some θ ∈ X_A(ℚ) avoids them, and Φ(θ) ∈ V_A(ℚ) generates A. **So the scope (i) gap for nonics (A = K × ℚ) and primitive decics is RHJ_10 plus the ramified local conditions for X_A** (weaker than those for V_A, S67.2). RHJ_10 is field-independent and allowed by S66.1: the 3-primary input is supplied by Hooley's X_A(ℚ), not by the transfer.
- Covariant form: RHJ_10 asks for g with Tr(g³/f'³) = Tr(g⁵/f'⁵) = 0 in E (weights: θ weight 1, e_k weight k). Not attempted this session.

**S68.4 (p-field test of RHJ_10).** exact enumeration (`parts68.py`) + *unchecked* (field-theoretic arguments, short).
- A positive RHJ_10 gives V_{E′}(F′) ≠ ∅ for every field F′ ⊇ ℚ and every E′ whose X_{E′}(F′) contains generators. Over p-fields the factor degrees of E′ are p-powers. **p = 2:** V has degree 15, so a general plane section has an orbit of odd size, i.e. a smooth F′-point. **p = 5:** the types [5,5], [5,1⁵], [1¹⁰] all have a split node; the quadric of Y_ν (8 variables) has Witt index 4 (no quadratic extensions), so it contains F′-spaces P³, on which the cubic is a cubic surface with F′-points (a line meets it in 3 points, orbits have 5-power size), unirational; S68.1 then gives points. **p = 7:** [7,1,1,1]: the degree-7 factor is cyclic (the transitive 7-group of degree 7 is C7) and Kummer (μ7 ⊂ F′), so (π, 0, 0, 0) with π⁷ ∈ F′ is a smooth point (S64.4(a)); [1¹⁰] split. **p ≥ 11:** split. **p = 3:** [9,1] (X can fail, S66.1), [3,3,1⁴], [3,1⁷], [1¹⁰] (two disjoint pairs of F′-factors: involution points, S64.1), and **[3,3,3,1]**: with two isomorphic cubic factors, swapping them gives three ± pairs; **the single open type is E′ = L1 × L2 × L3 × F′ with three pairwise non-isomorphic cyclic cubics L_j = F′(t_j^{1/3})**. This replaces S67.3(e), whose 5-field argument used the singular digit point.
- For that type X_{E′} has the smooth point (1, −1, 0, 0) (constants on L1, L2; X is singular only at the 126 nodes), hence dense F′-points. The constant leading-term system of V (BR-style digits, k = 1, 3, 5): 3(y1 + y2 + y3) + y4 = 0, 3Σy_j³ + y4³ = 0, 3Σy_j⁵ + y4⁵ = 0, has the solution (1, −1, 0, 0), which is singular on V (y² takes the values 1 and 0); with S = y1 + y2 + y3 = 1 it forces y1, y2, y3 to be the roots of **3x³ − 3x² − 15x + 7** [exact: e2 = −5, e3 = −7/3; irreducible, discriminant 2⁸·3³·7, Galois group S3], which has no root in a 3-closed field containing ℚ. **So the leading terms of any F′-point of V_{E′} sit at the singular configuration (1, −1, 0, 0)** (heuristic: BR's valuation argument not redone). There (a type-2 point with four zeros) the cubic part of the tangent cone is a norm form of L3 (anisotropic) and the quadric part is universal, so the weighted exceptional divisor has smooth F′-points; whether they come from F′-points of V (F′ is not henselian) is the open test.
- **Status:** RHJ_10 passes every p-field test except [3,3,3,1] with distinct cubics, which is undecided. If V_{E′}(F′) has no generator there, no field-independent transfer exists and the quintic step itself needs cubic-type ℚ-arithmetic beyond X_A; if it has, RHJ_10 survives all p-field tests.
