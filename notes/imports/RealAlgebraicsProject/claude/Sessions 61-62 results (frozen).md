**S61.1 (row E with P dials in coefficient coordinates).** [exact] (`e61sym.py`, sympy) + [numerical] planted check.
- Write χ_u = w⁹ + a1w⁸ + … + a9 (a_k = (−1)^k e_k(u)) and the auxiliary cubic c = w³ + c1w² + c2w + c3. The crossing condition χ_u·c = V(w²) + R(w) (deg R ≤ 3) reads W_k = 0 for k = 1, 3, 5, 7, where W_k is the coefficient of w^{12−k} in χ_u·c, and V's top coefficients are b_m = W_{2m} (m = 1, …, 4). Equivalently, **the row-E nonics are exactly N(w) = quo(V(w²), c(w)) + t**: V any P-affine image of S (only its top five coefficients matter), c any monic cubic over P, t ∈ P (identity checked on random data). Special cases: c = w³ gives the odd engine w·V̂(w²) + t; c = w(w² + c2) with V(t) = (t + c2)(U_9(t) + aU_q(t)) (T_k(x) = x·U_k(x²)) gives the fact-7 members T_9 + aT_q + t, for finitely many (c2, a) per S (*unchecked*).
- Solving W1 = W3 = W5 = 0 for c: c1 = −a1, c2 = (a1a2² − a1a4 − a2a3 + a5)/D, c3 = (a1²a4 − a1a2a3 − a1a5 + a3²)/D, with D = a1a2 − a3. The good locus is Gn = 0, where Gn = −a1²a2a6 + a1²a4² + a1a2²a5 − a1a2a3a4 + a1a2a7 + a1a3a6 − 2a1a4a5 − a2a3a5 + a3²a4 − a3a7 + a5². It is **linear in a7 with coefficient D**; centred (a1 = 0) it is a3²a4 − a2a3a5 − a3a7 + a5² = 0, which is H_E.
- In the coordinates (c, b) the good locus in coefficient space is A³ × A⁴ (given c, b1, …, b4 are triangular in a2, a4, a6, a8), and J depends on b only.
- **T_6 fibre:** B3 = 0 and 4B4 = B2² (B_k the coefficients of the depressed V: B2 = b2 − 5b1²/12, B3 = b3 − 2b1b2/3 + 5b1³/27, B4 = b4 − b1b3/2 + b1²b2/6 − 5b1⁴/144), i.e. E6 = 0 (62 terms in a1, …, a6, **linear in a6**; centred: 27a3³a6 = −4a2³a3³ + 6a2²a3²a5 + 9a2a3³a4 − 12a2a3a5² + 27a3⁵ + 9a3²a4a5 + 5a5³) and E8 = 0 (130 terms in a1, …, a8, **linear in a8**). So the fibre X_{T6} = J⁻¹(T_6) is **the Tschirnhaus variety of an explicit rational 6-parameter family over ℚ**: a1, …, a5 and a9 free; a6, a7, a8 rational and triangular in them. **S62.1 (row B5: the identity, and L_135 is genuine).** [exact] (`b5sym.py`, sympy) + [numerical] planted end-to-end check (`b5plant.py`).
- Bézier (X, Y) = (α(t + s)² + β, cubic) and the graph y = S(x), S ∈ ℚ[x] of degree 5, under a P-affine map (x, y) ↦ (ax + b, cy + dx + e). The α, β dials are absorbed into the map, so τ ∈ K is good iff for some s, ζ ∈ P the 10 points y = (τ + s, ζ) ∈ K × P satisfy **p1 = p3 = p5 = 0** (degree-10 power sums: the w⁹, w⁷, w⁵ coefficients of Π(w − y_i) vanish), so that Π(w − y_i) = E(w²) + R(w) with E a monic quintic and R an odd cubic, **and E is P-affinely equivalent to a rational quintic up to linear terms**.
- Quintics modulo x-affine maps, y-scaling and added linear terms have **one invariant**: I = B2²/B3³ with, in power sums of the 10 points (odd ones zero), **B3 = (p2² − 10p4)/40** and **B2 = −(p2³ − 15p2p4 + 50p6)/300** (sympy, via Newton's identities; depressing checked). For I0 ∈ ℚ, x⁵ + I0x³ + I0²x² (I0 ≠ 0) or x⁵ ± x³ (I0 = 0) is a rational representative; the map uses a = √(−B3) or a rational expression in B2, B3 (P Euclidean). So **τ is good iff y ∈ L_135^{(10)}(K × P) with I(y) ∈ ℚ**.
- **The slice ζ = s = 0 is L_135 itself:** for u ∈ L_135, w·χ_u(w) = E(w²) + R(w) with E = V⁵ + a2V⁴ + a4V³ + a6V² + a8V and R = a7w³ + a9w. **Every u ∈ L_135 with distinct nonzero conjugates is genuine**: the Bézier is (t², −R(t)), birational (t = y/(a7x + a9)), and its crossings with the mapped graph are the nine u_i and t = 0. (Row E's analogue w³χ_u has an odd part of degree 5 and is genuine only on V_odd, S59.2; one auxiliary crossing instead of three removes that.)
- **Reduction (*unchecked*, short): r = 9 closes for K (over ℚ, and over P since S is rational and every dial is P) if the weight-0 function I(p2, p4, p6) takes a rational value at a P-point of L_135**, i.e. if some Ω_{I0} = L_135 ∩ {B2² = I0·B3³}, I0 ∈ ℚ, has a P-point (I0 = 0: the sextic hypersurface 50p6 − 15p2p4 + p2³ = 0 of L_135).
