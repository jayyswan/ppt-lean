# Z9 — Genus-2/4 hyperelliptic arc lengths, Abel–Jacobi inversion, Umemura route

Status: done (2026-11-06)

## (1) Which integrals

### 1.1 The drawable genus-2 family is exactly w² = D + q(u)², q any real cubic with P coefficients
- Arc length of y = c·p(λx+μ): speed = √(1 + (cλ p′(λx+μ))²); substitute u = λx+μ. [Proof]
- Affine images (shear/scale/rotate, P-valued) of the graph (x, p(x)) have speed √(Q(q)) with Q a positive-definite
  quadratic form in the slope q = p′, Q(q) = |M(1,q)ᵀ|². Completing the square: Q = C((q+β)² + D). [Proof]
- Under u-affine and value-affine maps every real cubic is equivalent to u³ + u, u³ − u or u³ (one shape modulus is
  killed by the value shift β). So with p = x⁴/4 ± x²/2 (rational) and P-valued affine data, the drawable speed curves
  are **all** w² = D + q(u)², q ∈ P[u] real cubic, D > 0: a 2-modulus family (e.g. q = u³ ± u + b, D free). [Proof]
- Rotation does not change arc length; one offset layer adds d·Δψ, ψ = arctan(slope) (elementary) [Proof, Y1a/W3].
  Offset towers after non-conformal maps add integrals of f(q)·q′(u) du, i.e. pulled back from the v = q line: elliptic
  integrals on z² = Q_k(v)Q_i(v) evaluated at v = q(u_endpoints) (same mechanism as W3 §1.1). Genus never rises. [Proof sketch]
- Sextic graphs: w² = D + q₅(u)², q₅ = A·p′(λu+μ) + σ with p′ ∈ ℚ[u] quintic: genus 4, 2 *rational* shape moduli
  (quintic up to affine–affine has 2 invariants), 1–2 P-moduli. [Proof]
- Other drawables: cubic Bézier speed² = x′² + y′² quartic ⇒ genus ≤ 1. power_law y = a x^(m/n): x = tⁿ gives
  w² = n² t^(2n−2) + a²m² t^(2m−2) (after removing t-power): binomial, superelliptic with μ_k automorphisms, *no moduli*
  (a scales out), Jacobian splits into CM pieces (e.g. y = x^(5/2): w² = 4 + 25a²t⁶ ≅ w² = 1 + t⁶). [Proof sketch]
- Structural fact [Proof]: (w − q)(w + q) = D, so φ = w + q has divisor 3∞₋ − 3∞₊: **∞₊ − ∞₋ is 3-torsion** in Jac
  for every drawable genus-2 curve (Pell/Abel pseudo-elliptic structure). Branch points are the roots of q = ±i√D:
  three points and their conjugates, all nonreal; real locus = one oval through ∞₊, ∞₋ (no real Weierstrass point).

### 1.2 Decomposition of the arc-length differential [Wolfram, checked by hand]
For q = u³ + a u + b, F = D + q² (normalised; general cubic by u-affine):
  w du = d(u·w/4) + (3(b²+D)/4)·du/w + (5ab/4)·u du/w + (3b/4)·u³ du/w + (a/2)·(u⁴ + a u²) du/w.
- H¹_dR of C∖{∞±} has basis u^k du/w, k = 0..4. Residues at ∞₊: u² ↦ −1, u³ ↦ 0, u⁴ ↦ a; so u³ du/w and
  (u⁴ + a u²) du/w are second kind, and u² du/w is the third-kind form (≡ (1/3)(dφ/φ − a du/w), φ = w + q, elementary).
- **The third-kind (log) part of w du is zero** (consistent with w = q + D/(2q) + …, no 1/u term). [Proof]
- So one arc length = algebraic term [u w/4] + α₀ I₀ + α₁ I₁ (holomorphic, α₀ = 3(b²+D)/4, α₁ = 5ab/4)
  + β₃ J₃ + β₄ J₄ (second kind), fixed coefficients. One real functional per curve; the four pieces are not separately
  available (different curves have different Jacobians).
- Wolfram input: q=u^3+a u+b; F=d+q^2; R=r1 u+r0; expr=Expand[F-(D[R,u]F+R D[F,u]/2)-Sum[c[k]u^k,{k,0,4}]];
  Solve[CoefficientList[expr,u]==0,{r1,r0,c[0],...,c[4]}] → R = u/4, c = {3(b²+d)/4, 5ab/4, a²/2, 3b/4, a/2}.

### 1.3 Which values are P-numbers
- P-numbers: Φ(u₂) − Φ(u₁) for P endpoints u₁,u₂ (Φ = ∫ w du), any P-linear combination across arcs and curves. [Proof]
- Periods: **no real arc is a closed cycle** — the real oval is A + ι(A) with ι* = −1 on holomorphic forms and on
  second-kind forms modulo exact, so its periods vanish; finite real segments never pass ∞± (w du has poles there, so
  arcs through ∞ are infinite). The complete integral ∫_{∞₋}^{∞₊} of a holomorphic form along the real line is a 1/3-period
  (3-torsion above) but it is not a P-number: the arc-length differential diverges there. [Proof sketch]
- Real Abel sums (as in the elliptic complementary-arc trick F(φ)+F(ψ) = K) could in principle produce one real
  combination of periods of w du plus algebraic terms [Open; not found]; even then it is one number per curve, not Ω.

### 1.4 When does the Jacobian split? [Wolfram, Heuristic]
- b = 0 (q odd ⇔ p even after a shift, i.e. the quartic graph has a mirror axis): F is a polynomial in u², so
  u ↦ −u splits J ~ E₁ × E₂ with E₁: w² = D + t(t+a)², E₂: s² = t(D + t(t+a)²) (t = u²) [Proof, standard]. L-polys of
  w² = 1 + (u³+u)² factor into quadratics at every good p ≤ 41 [Wolfram]. Arc length then is elliptic (genus 1, H4 machinery).
- b ≠ 0 (generic quartic): w² = 1 + (u³+u+1)². Frobenius L-polynomial irreducible over ℤ at p = 7..79 for most p, and
  the polynomial of α_i^k stays irreducible for k = 1..6 at p = 11, 13, 29, 37, 43, 47, 59, 67, 73, 79 ⇒ no geometric
  splitting over any extension of exponent ≤ 6 [Wolfram]. Squarefree part of c₁² − 4(c₂ − 2p) varies (10, 33, 21, 7, 97,
  109) ⇒ no real multiplication [Wolfram, Heuristic]. So **generic quartic-graph arc length is a genuinely genus-2,
  geometrically simple abelian integral** (End = ℤ heuristically).
- Oddity [Open, not needed]: c₁ = 0 at p = 7, 17, 19, 53, 71 (5/19), more often than Sato–Tate USp(4) predicts.
- Wolfram input (point count over F_p and F_{p²} by hand-rolled F_p[√nr]; L = 1 + c₁T + c₂T² + p c₁T³ + p²T⁴,
  c₁ = N₁ − p − 1, c₂ = (s₁² − s₂)/2): see function `lp[cA,cB,cD,p]` in the handoff log entry for step 2.

## (2) Inversion

### 2.1 Only triangular single inversions exist [Proof sketch]
- Lemma S (Z4): every curve constructor is unary (one curve + P-numbers); readouts (inter, box, arc_length) return
  numbers. arc_of_length returns a *sub-arc of its input*, whose far endpoint is then read by box. Hence each
  PConstructible number is produced by one node of a finite derivation tree from earlier numbers, and the only nodes that
  involve an integral are: forward `arc_length` (Φ(u₂) − Φ(u₁)), and one-equation inversion u* = Φ_S⁻¹(Φ_S(u₀) + s) on a single
  curve S whose parameters are earlier numbers (box picks the branch).
- Checked candidates for coupling two conditions, all reduce to triangular form u₁ = f(s₁), u₂ = g(u₁, s₂):
  (a) intersect two arc_of_length arcs: the crossing is a point of S ∩ T (algebraic/elementary in the curves' parameters);
      the arc lengths only decide *whether* the crossing lies on the arc (an inequality/selection, not an equation);
  (b) box of an arc: either the far endpoint (single inversion) or an interior extremum (algebraic critical point);
  (c) offset of an arc: parallel arc, endpoints = offsets of the old endpoints (functions of one inversion output);
  (d) a curve parametrised by arc length on another curve (coordinates (Φ₁(u), Φ₂(u)) or x = Φ(u)): **no constructor builds
      it**; every drawn curve is algebraic or Pfaffian-elementary (sine, exp_two) in its parameter (Lemma S + offset formula).
  (e) nesting: arc_of_length on a curve translated/scaled by an earlier inversion output: triangular.
- Abel–Jacobi inversion on genus 2 is the *symmetric* system Σᵢ ∫^{uᵢ} ω_j = s_j (j = 1, 2), with ω₁, ω₂ holomorphic and
  both unknowns coupled. It is not of triangular form. Whether its solutions can nevertheless coincide with triangular
  compositions is a differential-algebraic question: [Open]. No topological obstruction can exist (Kolmogorov–Arnold:
  every continuous function of 2 variables is a superposition of 1-variable functions and +), so any impossibility proof
  must be differential-algebraic (Jacobi: a single genus-2 integral has an infinitely-valued inverse with dense period set).
- Moreover arc length is not even a holomorphic integral: Φ = α₀I₀ + α₁I₁ + β₃J₃ + β₄J₄ + algebraic (1.2), a fixed
  combination including second-kind parts, so even a "two-curve" system would not be the Jacobi system. [Proof]

### 2.2 Algebraic special values of a single inversion
- (Trivial) s built as Φ(u₁) − Φ(u₀) from a P-point u₁ returns u₁. [Proof]
- (Abel relations) On genus 2, deg-2 divisors are rigid (h⁰ = 1 unless a hyperelliptic pair): no relation P_a+P_b ~ P_c+P_d.
  The first non-trivial relations are pencils |D|, deg D = m ≥ 3, h⁰ = m − 1: after choosing m − 2 points of D′ the last two
  are the roots of a quadratic over P(earlier). The arc-length differential has no third-kind part, so the Abel sum is
  [algebraic + (no log)]; poles are at ∞± only. Hence every endpoint an Abel relation can force is quadratic over P: **nothing
  new** [Proof sketch].
- (Torsion) Points P ∈ C with P − ∞₊ torsion: finitely many per curve (Raynaud); for P(u*) they require
  s = rational combination of periods/quasi-periods of w du + algebraic. Genus-2 periods of drawable curves are not P-numbers
  (1.3: no closed real cycle; real oval has zero holomorphic periods; ∞± are at infinite arc length). The given 3-torsion point
  ∞₋ is itself at infinite length. [Proof sketch; the 'real Abel sums give a period' loophole is Open, 1.3]
- (Generic) Algebraic data, algebraic u* and Φ(u*) − Φ(u₀) ∈ ℚ̄: excluded except degenerate cases by Wüstholz (W3 §1.3)
  [Cited; application Heuristic]. So outputs of genus-2 inversions at algebraic data are transcendental except as above.
## (3) Galois groups reachable

- **2-torsion** = splitting field of the branch polynomial D + q² = (q − i√D)(q + i√D) [Proof]:
  - genus 2 (quartic graphs): two conjugate complex cubics ⇒ group ⊂ S₃ ≀ C₂, solvable; Weierstrass points already in P(i)
    by complex radicals (W3/X1). [Proof]
  - genus 4 (sextic graphs): two conjugate complex quintics ⇒ ⊂ S₅ ≀ C₂, only A₅. **Sharp form [Proof]:** with
    p = x⁶/6 + x²/2 (p′ = x⁵ + x) and P-affine data, the branch points are exactly the roots of the Bring–Jerrard
    quintic z⁵ + z + c and conjugates, for arbitrary complex c = (σ ± i√D)/A ∈ P(i) (σ real, D > 0). That is X1's
    missing (BR₅). So the genus-4 drawable Jacobians' 2-torsion = the (BR₅) fields; any route to their Weierstrass points
    (e.g. Thomae from theta constants) would close X1's swap case T×T for A₅ — but see (4): no such route exists in P.
- **ℓ-division (ℓ odd)**: generic image GSp(2g, ℓ) (genus-2 example of 1.4 has End = ℤ heuristically), composition factors
  PSp(2g, ℓ) + cyclic. In the drawable family the mod-3 image fixes the class [∞₊ − ∞₋] (a parabolic subgroup). Division
  values need Abel–Jacobi inversion (2.1) — not available; P's algebra cannot reach them either (PSp(4,3) has minimal
  permutation degree 27 > 8). [Proof sketch]
- **A_n, n ≥ 9 — genus ceiling [Proof mod citations, from memory: Wagner 1976–77 / Kleshchev–Tiep for minimal projective
  degrees of A_n, Feit–Tits 1978 for sections of linear groups]:** a nonabelian composition factor of a subgroup of
  GSp(2g, ℤ/N) has a projective representation of degree ≤ 2g in some characteristic ℓ | N, or is Lie type in char ℓ.
  A_n (n ≥ 9) needs degree ≥ min(n − 2, spin 2^⌊(n−3)/2⌋) ≥ 7. Hence:
  - genus 2 (all drawable genus-2 curves): torsion/division Galois data **never** contain A_n, n ≥ 9 — the same ceiling
    as W3/H4's elliptic one (A₅, PSL(2,p)), lifted to PSp(4,ℓ) and its subgroups (A₆, A₇ appear, nothing bigger);
  - genus 4: A₉, A₁₀ are possible only in 8-dimensional symplectic modules — classically Sp(8,2) ⊃ S₁₀ = 2-torsion of a
    hyperelliptic curve with 10 *free* branch points. Drawable genus-4 2-torsion is ⊂ S₅ ≀ C₂, so not this. A_n, n ≥ 11:
    never from genus ≤ 4 torsion.
  - Drawable arc-length curves have genus ≤ 4 in the relevant pieces (offset towers split into elliptic pieces, W3).
- **Monodromy of the inversion step** u*(params) is infinite (it contains the period lattice); as in W3 the content for
  algebraic outputs is the discrete monodromy at special (torsion) values, bounded as above. [Heuristic]

## (4) Umemura route

Umemura (Mumford, Tata II appendix): roots of f (deg n) = algebraic expressions in θ[η](0, Ω), Ω = period matrix of
y² = f(x)·(x) (genus ⌊(n−1)/2⌋). Ingredients and status in P:

| ingredient | in P? |
|---|---|
| (U1) a curve whose branch polynomial is the *target* f (deg ≥ 9) | **No.** Every arc-length curve has w² = x′² + y′² = (x′+iy′)(x′−iy′): a norm form, branch points are the roots of x′ + i y′ (deg ≤ 5 for poly_graph, ≤ 2 Bézier, binomial for power_law; towers: elliptic pieces). Real roots only double. [Proof] |
| (U2) complete periods (integrals over closed cycles) | **No** for genus ≥ 2: no closed real cycle; the real oval A + ι(A) has zero holomorphic periods; ∞± at infinite length (1.3). Genus 1 only (ellipse ⇒ K, E). [Proof sketch; real-Abel-sum loophole Open] |
| (U3) Abel–Jacobi / two-condition inversion | **No** (2.1): triangular single inversions only. [Proof sketch] |
| (U4) θ[η](0,Ω) from Ω (q-series) | **No**: no infinite summation operator; the only θ↔period bridge P has is θ₃² = 2K/π (genus 1). Thomae needs the roots (circular). [Proof sketch] |
| (U5) exp/cos/sin of entries, algebraic Thomae/Umemura last step | Yes (exp, cos, sin of P-numbers; field ops; degree ≤ 8 roots). |

**Single blocking operation:** (U1) blocks first and is structural (sum-of-two-squares speed, poly_graph cap 6): no
operation on *existing* curves can make the target's roots branch points. Granting (U1) hypothetically, the next single
missing operation is **(U4) evaluation of genus-g theta constants (equivalently Siegel modular inversion / the
coefficients-to-Ω period map with complete periods (U2))**. For the drawable genus-4 curves alone, (U2)+(U4) would yield
exactly (BR₅) (3), not A_n for n ≥ 9.

## (5) Verdict

- **No hyperelliptic/theta route to A_n (n ≥ 9) in P** (route-negative only; nothing about the target). Reasons, in order:
  (i) drawable arc-length curves are w² = D + q(u)² (q cubic ⇒ genus 2, 2 P-moduli; q quintic ⇒ genus 4), branch sets of
  degree ≤ 5 [Proof]; (ii) only triangular single inversions exist, never Abel–Jacobi [Proof sketch; impossibility of
  coincidence Open]; (iii) genus ≤ 4 torsion never carries A_n, n ≥ 11, and A₉/A₁₀ only via 10-branch-point 2-torsion
  [Proof mod citations]; (iv) Umemura needs (U1)–(U4), none present.
- **New facts found (positive, small):**
  - [Proof] The drawable genus-2 arc-length family is *exactly* {w² = D + q², q real cubic over P}; ∞₊ − ∞₋ is 3-torsion
    (φ = w + q); w du = d(uw/4) + 2 holomorphic + 2 second-kind terms, **no log part** (1.2).
  - [Wolfram, Heuristic] Non-symmetric quartic graphs (b ≠ 0) give geometrically simple, End = ℤ genus-2 Jacobians —
    genuinely new transcendentals (arc lengths), but not a Galois source. Mirror-symmetric quartics (b = 0) split ⇒ elliptic.
  - [Proof] Sextic-graph arc-length curves have as branch points the roots of z⁵ + z + c, c ∈ P(i) arbitrary: a
    geometric home for X1's (BR₅). Smallest concrete new capability that would pay off: **genus-4 theta constants /
    complete periods of these curves ⇒ (BR₅) via Thomae** — not available in P; recorded as a target, not a route.
- **Open:** (a) can real Abel sums (complementary-arc trick) yield a genus-2 period combination as a P-number? (b) a
  differential-algebraic proof that triangular single inversions never realise Jacobi inversion values; (c) the excess of
  c₁ = 0 primes for w² = 1 + (u³+u+1)².
