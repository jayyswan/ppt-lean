# Q3 — Making the condition variety many-variable quadrics

Status: done (2026-11-06)

## (1) Theorem R generalised

### 1.0 The invariant that decides every circle-method attempt [Proof]
Every route asks for an L-point (L ⊂ E or F) of a variety over ℚ twisted by K = ℚ(β). Count over L̄,
where K ⊗ L̄ = L̄ⁿ:
- an L-unknown (a P-valued drawing parameter) is 1 variable; a K-unknown (τ, a square root ρ, a
  K-valued slope) is n variables;
- a K-equation is n L-equations (Galois conjugates, equal degree).

With M L-unknowns, u K-unknowns and e K-equations (independent), dim X = M + n(u − e) and X is cut
out by R = ne equations. Every circle-method theorem needs dim X large compared with R:
- Birch / Skinner / Frei–Madritsch (Theorem H(d)): N > R + R(R+1)(d−1)2^(d−1), i.e. dim ≳ 2R² for
  quadrics;
- the strongest *linear-in-R* bounds (Myerson, §4; over ℚ only) need N ≥ 9R for quadrics (smooth CI), i.e. dim ≥ 8R;
- Theorem H(a) needs dim ≥ (deg X − 1)2^deg X − 1.

So the design target is **dim X ≥ c·n·e**, with c ≥ 8 at the very least (linear bounds) or c ≈ 2ne
(Birch). If u = e (each auxiliary K-unknown is pinned by its own K-equation, as ρ_j is), this reads
**M ≥ c·n·e**: P-parameters must exceed n × (number of K-conditions) by a constant factor (best case)
or by 2ne (Birch). This is the precise quadric form of (BD).

### 1.1 Theorem R's incidence variety, counted [Proof]
Normalise b₁₁ = 1 (a positive L-multiple of Q_j gives the same drawable term; √b₁₁ ∈ P). Then
Q_j(τ) = (τ − b_j)² + c_j with c_j > 0, and the condition variety is

  X_J = {(τ, b, c, ρ) : ρ_{j,i}² − (τ_i − b_j)² − c_j = 0, i = 1..n, j = 1..J}

(after homogenising: quadrics in N = n + 2J + nJ + 1 variables, R = nJ equations, dim X_J = n + 2J).
The linear unknowns (c′, a, δ) are disposed of by Theorem R once J ≥ n − 1 (or n − 2, §1.2c).
- Birch (d): needs n + 2J > 2nJ(nJ+1): false for all n, J ≥ 1.
- Linear bound N ≥ 9R: n + 2J + nJ + 1 ≥ 9nJ: false for all n ≥ 2, J ≥ 1.
- The fibre over fixed τ is (V_τ)^J (diagonal-quadric surfaces): nothing couples, so a circle method
  has nothing to exploit. The fibre over fixed forms is R_{K/L}C_B (dim n, general type for J ≥ 3).

The deficit is not the *number* of unknowns (≈ n², as wanted) but the dimension: every new unknown
ρ_{j,i} brings its own equation. **dim/R = (n + 2J)/(nJ) → 0.**

### 1.2 Can a construction break the ratio? Source by source [Proof sketch unless marked]
(a) **Forms in more variables.** Prop T: every non-base summand of a drawn tower is d·√Q(u) with Q a
  binary form in the final normal u = (s, −1), and the crossing has ONE normal direction s ∈ ℙ¹(K).
  So the square conditions are always Q_j(1, τ) with Q_j binary quadratic (3 coefficients, n
  equations). Q_j(1, τ, …, τ^k) would need a summand whose support is √(degree-2k polynomial in s);
  offsets add only disks and affine maps make them ellipses (Z4). Not available.
(b) **Several field elements (τ, σ, …).** A second K-valued slope needs a second curve in the
  crossing. Tower T(s) against curve C(t): 2 K-equations, unknowns s, t; square conditions fall on s
  (T's forms) and t (C's forms) separately, so the fibre over (s, t) is V_s^{J_A} × V_t^{J_B} and the
  linear unknowns needed rise to 2n + 1. If C is rational (Bézier, poly_graph) it adds ≤ 8 linear
  unknowns and no square conditions, but costs a whole K-equation (n L-equations): a net loss for
  n > 8.
(c) **The base curve G.** It contributes one summand h₀(P₀ᵀu); rational h₀ gives K-values for free.
  - **Small positive [Proof + Wolfram].** A cubic Bézier whose x(t) is quadratic (one linear
    condition on the P-control points, −x₀ + 3x₁ − 3x₂ + x₃ = 0) is parametrised by tangent slope:
    x = 3as² + 2bs, y = 2as³ + bs², support h = as³ + bs², and D_{e₂}h = sh′ − h = 2as³ + bs² is
    LINEAR in (a, b). So the base gives two linear unknowns (functions s², s³), not one, and
    Theorem R needs **J ≥ n − 2** square forms instead of n − 1. (It is an affine image of
    y = x^{3/2}, Y1a's (t², t³) case; the shift in κ(s − σ₀)³ is linear after reparametrising
    (a, b) = (κ, −3κσ₀). Restrict away from the cusp s = −b/(3a).) For (t^k, t^{k+1}), k ≥ 3,
    κ(s − σ₀)^{k+1} mod ⟨1, s⟩ is a nonlinear cone: no further gain.
  - An algebraic base (rational sextic `poly_graph`) has h₀(τ) ∈ K iff τ = f′(x*) with x* ∈ K;
    choosing x* freely only re-parametrises τ, which was free already. No gain.
(d) **Several towers sharing τ.** See (2): the ratio gets worse.
(e) **Non-square ρ_j.** Y1a §4.5: the crossing identity splits by square class; a non-trivial class
  needs ≥ n + 1 forms inside it, which is the same problem one level up.
(f) **Offset layers used non-linearly (W1).** Eliminating radicals by norms gives n equations of
  degree δ ≥ 2^j in M = 3j + 4 parameters; even a linear-in-R bound of shape d2^dR (§4) needs
  M ≳ nδ2^δ, unreachable because M is logarithmic in δ.

**Conclusion of (1) [Proof sketch, scoped to the Prop T + Z4 constructor set].** Beyond O(1) base
parameters, every linear P-parameter comes from an ellipse summand, and each ellipse summand costs
one K-condition (n L-equations) while adding ≤ 4 L-unknowns (3 form coefficients + δ). Hence
dim X ≤ 4e + n + O(1) against R ≥ ne, i.e. dim/R ≤ 4/n + 1/e + o(1). No known circle-method theorem,
and not even the conjectural square-root-cancellation range (dim ≳ 3R for quadrics), is reachable.
Making unknowns grow like n² is easy (X_J has ≈ n²); making the *excess* grow needs a new
constructor: a drawable family with ≥ c·n P-parameters per K-condition.

Wolfram input (1.2c): `TimeConstrained[Module[{a,b,s,x,y,h}, x=3a s^2+2b s; y=2a s^3+b s^2;
h=a s^3+b s^2; {Simplify[D[y,s]/D[x,s]], Simplify[x-D[h,s]], Simplify[y-(s D[h,s]-h)],
Coefficient[Expand[x/.s->s0+w t],t,3]}],20]` → {s, 0, 0, 0}.

## (2) Several towers sharing one target

**Count [Proof].** Let configurations t = 1..T have condition varieties X_t (dim m_t, cut by R_t
L-equations), each fibred over the slope/target K-unknowns.
- *Independent towers, any one readout suffices:* nothing is shared, and the best single X_t
  decides. No gain.
- *Shared target τ (fibre product over R_{K/L}𝔸¹_τ, n-dimensional):* dim = Σm_t − (T−1)n, R = ΣR_t.
  The ratio dim/R drops. For Theorem R towers with J_t forms each, the fibre over τ is
  ∏_t V_τ^{J_t}: the square conditions do not interact at all.
- *Two towers crossing each other (T_A(s) = T_B(t)):* 2 K-equations, so ≥ 2n + 1 linear unknowns
  are needed, i.e. about 2n square forms: §1.2(b).
- *gcd recovery across engines.* Readouts X_A, X_B ∈ P with β₁ ∈ L(X_A, X_B) but β₁ ∉ L(X_A) or
  L(X_B): e.g. X_A generates L(β₁ + β₂) and X_B generates L(β₁ + β₃); then
  Stab{1,2} ∩ Stab{1,3} fixes 1, so β₁ ∈ L(X_A, X_B). But each readout field then has degree
  ≥ C(n,2) for Gal ⊇ A_n (n ≥ 9), and Theorem R over a field of degree C(n,2) needs ≈ C(n,2) square
  forms. Z7 [Proof] already shows every multi-readout scheme maps onto the single-factor case.
  No gain.

**Verdict (2) [Proof].** Sharing a target never improves dim/R: dimensions add with a −n penalty
per shared K-unknown while equation counts add. Several towers multiply unknowns *and* conditions
in the same proportion.

## (3) Square lift + quadrics

**Re-embedding cannot help [Proof].** Every projective variety is an intersection of quadrics in
a Veronese re-embedding, and any equation system can be made quadratic by auxiliary variables
y = (monomial). Each auxiliary variable comes with its own defining equation, so dim X is unchanged
while R grows. Circle-method thresholds are monotone in R at fixed dimension (H(d): N − R > 2R(R+1)
for quadrics), so quadratisation only makes them worse. "Quadrics" is useful only when the
quadric presentation is the natural one *and* dim X ≳ R (linear bounds) or ≳ 2R² (Birch).

**Square lift K' = K(γ), γ² = β − c (degree 2n, ≤ 2 real places) [Proof].**
- Theorem R over K': V′_τ = 2n − 3 diagonal quadrics in ℙ^{2n−1}; X_J′ has dim 2n + 2J against
  R = 2nJ, and J ≥ 2n − 2 (Bézier base). Same ratio, twice the size.
- Keeping τ ∈ K and allowing ρ_j ∈ K': K'^{×2} ∩ K^× = K^{×2} ∪ (β − c)K^{×2}, so ρ_j ∈ K or
  ρ_j ∈ Kγ. The crossing identity splits into a K-part and a Kγ-part (Y1a §4.5); the γ-class
  equation is homogeneous and needs ≥ n + 1 forms of its own. Multi-quadratic lifts
  K(√(β − c₁), …, √(β − c_k)) give 2^k classes and the same splitting. No gain.
- Theorem X's trinomial variety I_{K'} is a surface; Theorem R over K' is the same count as
  above. Realness was the lift's purpose, and Theorem R has it for free already.

**Low-dimensional tools on V_τ [Proof].** At n = 7, V_τ = 4 quadrics in ℙ⁶. Every member of the web
is Σν_iρ_i² with ν ∈ K (the trace form Tr(νρ²)), signature (#ν_i > 0, #ν_i < 0), so Witt index ≤ 3;
Theorem W needs 4 (8 variables). Planes in Q₁ ∩ Q₂ ⊂ ℙ⁶ form a J[2]-torsor of the hyperelliptic
curve y² = det(xQ₁ − Q₂) = ∏(xμ_{1,i} − μ_{2,i}), whose Weierstrass points are the conjugates of
μ₂/μ₁ ∈ K: the 2-torsion field is K's Galois closure, not inside E (that would already give β).
So the twist by K blocks every slicing of V_τ, as B1 found for curves.

**By-product: Lemma Q (quadric systems over E without a circle method) [Proof sketch; genericity
at each stage not verified].** Let X = Q₁ ∩ … ∩ Q_r ⊂ ℙ^N over a subfield of E be a smooth complete
intersection with a smooth real point x, in general position. If N ≥ f(r) with f(r) = f(r−1) + r,
f(3) = 3 (Lemma A covers r ≤ 3 in any dimension), so f(r) ≈ r²/2, then X(E) is dense near x.
- Induction: take v₀ ∈ X_{r−1}(E) near x (X_{r−1} = Q₁ ∩ … ∩ Q_{r−1}). Lines through v₀ in X_{r−1}
  are the cone over Y = X_{r−1} ∩ {Q_i(v₀, ·) = 0, i < r} ∩ (complement of v₀): r − 1 quadrics in
  ℙ^{N−r}, nonempty and real near the real line through x when N − r − (r − 1) ≥ 1. By induction
  Y has E-points near it; the E-line v₀v₁ meets Q_r in 2 points, the one near x is real, so lies
  in E(√·) = E (E Euclidean).
- So E is "real-C₀ for quadric systems" with a *quadratic* bound, like Leep's u_r bounds, and with
  no Hasse principle or number-field circle method needed. It does not rescue any route: V_τ is
  n − 3 quadrics in n variables (needs n − 1 ≥ (n − 3)²/2, i.e. n ≤ 5, where V_τ is rational
  anyway), and X_J has dim n + 2J against r = nJ.

## (4) Literature: bihomogeneous / block-linear Birch-type theorems

Sources opened (abstract pages; Hochfilzer's theorem statements read from the PDF text):
- **Rydin Myerson, "Quadratic forms and systems of forms in many variables", Invent. Math. 213
  (2018) 205–235, arXiv:1512.06003 [Cited].** R quadratic forms over ℤ, V(F) a smooth complete
  intersection, **n ≥ 9R** ⇒ asymptotic for integer points in expanding boxes, hence the smooth
  Hasse principle. Unconditional for quadrics. (Earlier results needed n quadratic in R.) The
  extension to degree d is conditional on an auxiliary-inequality bound.
- **Rydin Myerson, "Systems of forms in many variables", arXiv:1709.08917 [Cited].** R forms of
  degree d, n ≥ d2^dR + R, coefficients in an explicit Zariski-open set (generic systems only).
- **Hochfilzer, "Systems of bihomogeneous forms of small bidegree", Acta Arith. 213 (2024) 325–368,
  arXiv:2305.16159 [Cited, Thms 1.1–1.2].** Over ℤ, lopsided boxes P₁ = P₂^b etc.
  - Bidegree (1,1), V ⊂ ℙ^{n₁−1}×ℙ^{n₂−1} a CI: n_i − 𝓡^{(i)} > (2b+2)R; if smooth,
    min(n₁, n₂) > (2b+2)R and n₁ + n₂ > (4b+5)R (b = 1 for square boxes: > 4R, sum > 9R).
  - Bidegree (2,1) (x quadratic, y linear: xᵀH_i(y)x): n₁ − s^{(1)} > (8b+4u)R and
    n₁/2 + n₂ − s^{(2)} > (8b+4u)R; if smooth, **n₁ > (16b+8u+1)R, n₂ > (8b+4u+1)R**
    (b = u = 1: n₁ > 25R, n₂ > 13R). Linear in R, removing Schindler's quadratic requirement.
- **Schindler, "Bihomogeneous forms in many variables", J. Théor. Nombres Bordeaux 26 (2014)
  483–506 [Cited, via Hochfilzer's summary]:** variables quadratic in R. Browning–Hu, "Counting
  rational points on biquadratic hypersurfaces", Adv. Math. 2019, arXiv:1810.08426: one (2,2)
  form, n > 35 (Schindler's general bound gives n > 193).
- **Flores Galiote–Yeon, "On weighted forms in many variables", arXiv:2608.28774 (Aug 2026)
  [Cited, abstract]:** one weighted form F(x; y), weights w₁ < w₂ coprime, needs d > w₁w₂ and
  s₁ + s₂ − σ_F > (1 + w₂/w₁)(d/w₁)2^{d/w₁}. Our square conditions ρ² = b₀ + b₁τ + b₂τ² are
  weighted of weights (1, 2) and degree 2, so d > w₁w₂ = 2 fails; single forms only anyway.
- **Number fields.** No number-field version of Myerson's or Hochfilzer's linear bounds was found
  (one search; Skinner 1997 is Birch-type). Browning–Pierce (arXiv:2212.11038) note the bijection
  between quadratic forms over K and systems of d = [K:ℚ] rational quadrics in dn variables.

**Transfer to number fields: does NOT follow naively [Proof of the obstruction; Open as to a fix].**
For X ⊂ ℙ^{N−1}_L a smooth CI of R quadrics, the Weil restriction of the affine cone is, over ℚ̄,
the product of the d = [L:ℚ] conjugate cones: dR rational quadrics in dN variables, with the same
variables/equations ratio. But the product of cones is singular wherever one factor is at its
vertex, so the projective variety in ℙ^{dN−1} is singular along a locus of dimension
≈ (d−1)(N−R) − 1. Myerson's theorem assumes V(F) nonsingular, so it does not apply; Birch-type
bounds that tolerate a singular locus of dimension σ then need dN − σ ≈ N − R + R large,
which loses the linear gain. A genuinely number-field version of Myerson (not found) would give
"Theorem H(f): smooth CI of R quadrics in N ≥ 9R variables over L₀ ⊂ E with a smooth real point ⇒
dense E-points" via Lemma LS. Recorded as [Open]; it would not rescue any route anyway (below).

**Effect on the routes [Proof of the arithmetic].** Linear bounds change the target from
dim ≳ 2R² to dim ≳ 8R, but every route variety has dim/R → 0 (§1):
- V_τ: n variables vs 9(n − 3): only n ≤ 3.
- X_J: n + 2J + nJ + 1 vs 9nJ: never.
- (2,1)-structure: the square conditions are "linear block b, quadratic block ρ", but as a sum
  (0,1) + (2,0), not bidegree (2,1); and eliminating the linear block exactly gives V_τ again, so
  no block-linear theorem can do better than on V_τ. Theorem R's crossing equation is genuinely
  bilinear in (δ) × (1/ρ), but the ρ are pinned by the squares.
- Lemma Q (§3) gives quadric systems over E with N ≈ r²/2, no circle method; a hypothetical
  Theorem H(f) would need 9r. Neither reaches dim/R → 0.

## (5) Verdict

**Status (2026-11-06).** No construction comes into the range of Theorem H, W, Lemma Q, or any
bihomogeneous/linear-in-R theorem, for any n. Every claim below is scoped to the current
constructor set (Prop T + Z4). Nothing here is a negative about the algebraic target.

**The decisive invariant [Proof].** Circle-method tools need the *dimension* of the condition
variety to be large compared with its number R of equations: dim ≳ 2R² (Birch / Frei–Madritsch),
dim ≥ 8R (Myerson, ℚ only), dim ≳ R²/2 (Lemma Q over E). The number of variables is irrelevant
once auxiliary unknowns come with their own equations (§3). In a K-twisted problem each
K-condition is n equations, so the requirement is **P-parameters ≥ c·n per K-condition**.

**Best construction found:** Theorem R with a Bézier base (§1.2c, new: J ≥ n − 2 square forms
instead of n − 1).
- Variables: τ (n), forms (2J), roots ρ (nJ): N = n + 2J + nJ + 1 homogeneous.
- Conditions: R = nJ quadrics, ρ_{j,i}² = (τ_i − b_j)² + c_j.
- dim = n + 2J ≈ 3n; R ≈ n².
- Real point: yes, totally real included. Point type: E/F (no poly_graph coefficients).
- Range: Birch needs dim ≳ 2n⁴, Myerson ≳ 8n², Lemma Q ≳ n⁴/2. **Out of range for every n ≥ 4.**
  The fibre over τ is (V_τ)^J, uncoupled surfaces; the K-twist also blocks every slicing of V_τ
  (§3: its 2-torsion/plane data live in K's Galois closure).

**Why nothing better exists inside the constructor set [Proof sketch].** Linear P-parameters
beyond O(1) come only from ellipse summands, each costing one K-condition and adding ≤ 4
L-unknowns: dim/R ≤ 4/n + 1/e + o(1) → 0 (§1.2). Sharing a target across towers makes it worse
(§2). Lifts and quadratic re-embeddings keep the ratio (§3). Non-linear (W1) use of layers makes
the degree grow like 2^j against 3j parameters.

**What would close it.** A drawable family with ≥ 8n P-parameters per K-condition and bounded
degree. That is (BD), sharpened by the linear bounds from Q2's M ≳ n² to **M ≳ 9n per K-condition**
(if a number-field Myerson existed) or M ≳ n²/2 (Lemma Q, unconditional over E). It needs a
Minkowski-sum or two-curve operation, i.e. a new constructor (the user's decision).

**Partial wins (small, recorded for the record).**
1. Bézier base: J ≥ n − 2 square forms suffice in Theorem R [Proof + Wolfram].
2. Lemma Q: r quadrics in ≈ r²/2 + O(r) variables, smooth real point, general position ⇒ E-points
   dense, with no circle method [Proof sketch; genericity at each step unverified].
3. Literature: Myerson's n ≥ 9R (quadrics, ℚ) and Hochfilzer's (2,1) bounds (n₁ > 25R, n₂ > 13R)
   are the right shape for a "many quadrics" route. Their number-field versions are not found, and
   the naive Weil restriction breaks Myerson's smoothness hypothesis (§4) [Open].
4. No range of n and no non-totally-real special case comes into range; small n (≤ 5) was already
   unconditional (V_τ rational).
