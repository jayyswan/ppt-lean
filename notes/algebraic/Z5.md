# Z5: rational and elliptic curves on V_tau (n = 9)

Research only. No Lean, git or PowerPoint. Labels: [Proof], [Proof sketch], [Wolfram], [Heuristic], [Open].
Scope: this blocks only the route "find a genus 0/1 L-curve on V_tau to get SS_{n-1}". It says nothing about the target.

## Verdict

**No hit, and structurally no hit.** For n = 9 (indeed n >= 9), V_tau contains NO L-rational curve of geometric genus 0 or 1
other than l_tau, for ANY generator tau, whenever Gal(K_L/L) is S_9 or A_9 (more generally, whenever the Galois module below has no small stable subgroup).
Any further L-curve has geometric genus g >= 2 and degree e <= 4(g-1) in P^8 [Proof sketch, section 2].
Genus-2 curves have finitely many points (Faltings), so the curve route is dead for n = 9. What remains is isolated points, i.e. SS_{n-1} itself (open).
Naive expected dimensions were already negative (section 1): conics -1, twisted cubics -4 for the incidence {(tau, C)} up to PGL_2.

## 0. Setup (from Y1a 4.1)
- W_tau = <1,tau,tau^2>_L in K_L (dim 3 in the n-dim L-space K_L), V_tau = {[rho] in P(K_L) = P^{n-1} : rho^2 in W_tau}.
  Over Lbar, with z_i = rho(beta_i): V_tau = {z : z_i^2 = a + b tau_i + c tau_i^2 for some (a:b:c)}, a smooth CI of n-3 diagonal quadrics.
  n = 9: P^8, six quadrics, a surface, K = O(3), deg 64, K^2 = 576, c_2 = 768, chi(O) = 112 [Proof; c(T) = (1+h)^9/(1+2h)^6].
  Since c_1^2 < c_2, Bogomolov finiteness of rational/elliptic curves does NOT apply; the argument in section 2 replaces it.
- Key reading [Proof]: pi: V_tau -> P^2 = P(binary quadratic forms Q), [rho] -> Q with Q(tau) = rho^2, is a (Z/2)^{n-1}-cover
  branched along the n lines l_i = {Q : Q(tau_i) = 0}. All n lines are tangent to the conic Delta = {squares (s-z)^2}, at (s-tau_i)^2.
  The preimage of Delta is the 2^{n-1} lines l_eps (z_i = eps_i (alpha + beta tau_i)); only eps = const is L-rational: that is l_tau.
  Positive definite forms are the points inside Delta.
- Nonic of Y1a section 5: q = prod_{i=-4}^{4}(x - i) + 1, totally real, Gal = S_9 [Proof from cycle types, Y1a]. Y1a searched tau = beta, 15625 directions of height <= 2

## 1. Dimension counts [Proof of arithmetic; Heuristic as predictor]
Degree-d rational curves in P^8: 9(d+1) - 1 parameters, minus 3 for PGL_2: 9d + 5. Conditions: each of 6 quadrics restricted gives 2d+1, total 12d + 6.
Expected dimension on a fixed V_tau: **-3d - 1** (= -K.C - 1). Conic -7, twisted cubic -10.

affine maps fix W_tau). Effective moduli: 9 - 3 = **6**, not n-1 = 8. Incidence {(tau, C)} up to PGL_2: **5 - 3d**: conic -1, cubic -4.

The real result is not dimensional; it is section 2.

## 2. Theorem Z5: no genus 0/1 L-curves [Proof sketch; checked numerically in section 4]

**Claim.** Let C in V_tau be geometrically irreducible, defined over L, geometric genus g, degree e in P^{N-1} (N = n lines), C != l_tau, tau_i distinct.
Let H = Gal(K_L/L) act on M = F_2^N / <diag> (the deck group). If the only H-stable subgroups of M are 0 and M (true for H = S_9, A_9, N = 9: M is the 8-dim heart), then
(N - 8) e <= 4g - 4. For N = 9: e <= 4g - 4, so g = 0 and g = 1 are impossible.

Proof sketch.
1. Trivial stabiliser. Stab(C) in M is H-stable (C is defined over L), so it is 0 or M. The kernel of Stab on C is also H-stable; a pointwise-fixed C lies in a coordinate subspace
   {z_I = 0}, not H-stable, so the kernel is 0. But (Z/2)^8 embeds neither in Aut(P^1) (elementary abelian rank <= 2) nor in Aut of an elliptic curve (rank <= 3).
   So Stab = 0 and pi|_C is birational onto D.
2. No base points. Parametrise the normalisation by z_i(t) of degree e with no common zero. f = (a,b,c) with z_i^2 = l_i(f) has degree 2e and no common factor (it would divide every z_i^2).
   So deg D = 2e and every vanishing order k_p of l_i.f is even, so >= 2.
3. Dual curve. Assume D != Delta. Riemann-Hurwitz for the Gauss map: d* = 2 deg D + 2g - 2 - kappa = 4e + 2g - 2 - kappa, kappa = sum_p (a1(p) - 1) (a1 = first positive vanishing order of f at p).
   Also D*.Delta* = 2 d*, and the n points l_i* lie on the smooth conic Delta*.
   - If l_i is the limit tangent at p, the dual branch has multiplicity k_p - a1(p) and contributes at least that to D*.Delta* at l_i*.
   - If l_i passes through p but is not the tangent, then k_p = a1(p) >= 2, contributing a1(p) - 1 >= k_p/2 to kappa.
   - At most two lines l_i pass through a point of P^2 (two tangents to a conic), and at most one is the tangent at p.
   A case check (one tangent pair; one non-tangent pair; two non-tangent pairs; tangent plus non-tangent) gives (k_p - a1) + 2(a1 - 1) >= (1/2) * (sum of k over pairs at p).
   Summing over all pairs: 2 d* + 2 kappa >= (1/2) * N * 2e = N e. The left side equals 8e + 4g - 4. So (N - 8) e <= 4g - 4.
4. D = Delta forces C to be one of the 2^{N-1} lines l_eps; only l_tau is L-rational. A line D has odd degree, impossible for a birational image of degree 2e. QED.

Consistency [Proof of arithmetic]: N = 5 (dP4) has exactly 2^4 = 16 lines l_eps. N = 6 (K3) has 32. For N = 5 the bound is -3e <= 4g - 4, allowing conics.
N = 8: g = 0 excluded, g = 1 allowed. N = 7: g = 0 needs e >= 4.
Field remarks. If the field of definition is a quadratic or real subfield L', run the argument with L' (Theorem R holds over any real L' closed under positive square roots).
If L' is disjoint from the splitting field, H is unchanged; if L' = Q(sqrt(disc)), H = A_9 and the heart stays irreducible. So the "real quadratic coordinates" relaxation does not help.
Geometrically reducible curves defined over L have only finitely many L-points (in intersections): unusable.
If L contained a subfield making H imprimitive (blocks of size 3), M could acquire small stable subspaces and step 1 weakens [Open for imprimitive H]; this is outside Y1a's setting.

## 3. Genus 1 [Proof sketch]
The same inequality gives e <= 0 at N = 9 for g = 1. No elliptic curve over L, of any rank, no hyperplane-section residual (a general hyperplane section has g = 129, e = 64, consistent with e <= 4g - 4),
and none from the Fermat-type quotient (Y1a 4.3), since step 1 kills every curve with nontrivial deck stabiliser.

## 4. Wolfram numerical check [Wolfram]
Conic search: rho(t) = u + v t + w t^2 in C^N, squares of each t-coefficient in W_tau, Gauss-Newton with pseudoinverse, |x| = 1, random real tau.
Genuine conic = plane curve (a,b,c)(t) of rank >= 2 with discriminant b^2 - 4ac not identically 0 (not on Delta).
- N = 5 (positive control): 30 starts, 30 converged, 6 genuine non-Delta conics.
- N = 6 (generic K3): 26 converged, 0 genuine. N = 7: 22, 0. N = 8: 27, 0.
- **N = 9: 28 converged, 12 non-point curves, all on Delta (l_eps lines and reparametrisations), 0 genuine.**
Consistent with Theorem Z5. Backend: Wolfram only. Not done: explicit tau = a + b beta + c beta^2 families on Y1a's nonic (the theorem covers every tau), twisted cubics numerically.
