# H3: arithmetic route for rational q of any degree n

Stream H3 of `pptc/PLAN-algebraic.md`. Labels: [Proof], [Cited], [Wolfram], [Heuristic], [Open]. Every obstruction is
scoped to the route it blocks; nothing here concludes a negative about the target. No `.lean` edits.
Notation: K = Q[x]/(q), n = deg q, s = number of conjugate pairs, tau in K, chi_tau its characteristic polynomial,
p_k = Tr(tau^k), e_k elementary symmetric functions, F_{<n} = closure of Q under real roots of degree < n.

## Findings summary

1. **Recovery is free [Proof].** If tau in K has chi_tau squarefree and y0 = tau(beta) lies in a field F, then
   gcd(q(x), tau(x) - y0) in F[x] is the linear polynomial x - beta, so beta is in F by field operations (Euclid). No composition
   structure phi o psi with degrees <= 6 is needed, and no degree-<n induction is used in recovery. (The repo's `nonic_recovery`
   uses degree-<=6 compositions for convenience.) The only real work is *producing y0* from a drawable crossing.
2. **Exact requirement and the dimension law [Proof].** Let the drawable rational family have F free parameters (affine
   dimension of the set of crossing polynomials N, scale included). Then chi_tau | N (overshoot, cofactor rho), and the locus W of
   good rational tau in P(K) = P^{n-1} has dimension F-2 and **codimension n+1-F**. Over C it is non-empty as soon as F >= 2
   (tau -> chi_tau is finite and dominant). Only rational (or F_{<n}) points are the issue. Sparse power-law x rational-sextic
   engines have F = 8 (N2), so the number of conditions is c(n) = n-7, **linear in n**.
3. **Forms in many variables cannot carry this for any n >= 11 [Proof that the hypotheses fail; scoped to the cited theorems and to
   bounded-F engines].** W is cut out by c = n+1-F conditions in n variables; Birch-type theorems need variables
   > (singular dimension) + c(c+1)(d-1)2^{d-1}-type constants, at least 2c(c+1) > n for c >= 3. For n = 10 the engine
   y^10 = sextic needs p_1 = p_2 = p_3 = 0, a quadric and a cubic in 9 trace-zero variables; the cited Hasse principles for a smooth
   quadric-cubic intersection need n >= 29 (Browning-Dietmann-Heath-Brown, secondary) or n >= 37 (Browning-Heath-Brown Cor 1.8).
   Meyer handles exactly the quadric alone, which is why n = 9 works and n = 10 is the first open case.
4. **More free parameters exist, but only in nonlinear families [Wolfram].** Measured F (Jacobian rank of parameters ->
   coefficients of N at a random rational point):
   - aligned power law x sextic: F = 8 (N2);
   - rational-affine parabola x rational sextic graph, N = Q(u) - G(P(u)) (degree 12): **F = 9**;
   - rational sextic graph x transposed sextic graph (rotate by 90 degrees), N(u) = mu*u - Gt(A(u)), Gt, A sextics (degree 36):
     **F = 13**. Every rational affine image of a sextic graph crossing a sextic graph reduces to this family [Proof, section 1].
   By the dimension law F = 13 is unconditional over C for n <= 12. But the incidence problem is then "find rational tau, sigma in K with
   sigma = A(tau), tau = Gt(sigma), degrees <= 6 both ways, sigma not in Q + Q tau": a nonlinear system with no linear-algebra
   step. I have no rational-point method for it [Open].
5. **Realness.** For totally real q and any real tau, p_2 > 0 [Proof; definite trace form; coefficients of tau in any real field,
   F_{<n} included]. So every shape with y^{m-1}, y^{m-2} both absent (all `y^m = sextic`) is out for totally real q. Working over a number
   field L does not repair this: the real place of L carrying the embedding L in R sees the same definite form [Proof]. For q with s >= 1:
   {p_2 = 0} has real points iff s >= 1, and real isotropic subspaces have dimension <= s (G1 R3).
6. **The square lift is never cheaper in this accounting [Proof of the count].** g(y) = f(y^2 + c), degree 2n. Wolfram: totally real
   degree-10 f, c = 9/2: g irreducible, degree 20, 2 real roots, trace-form signature (11, 9). Meyer then gives p_1 = p_2 = 0, but a sparse
   engine at degree 2n needs 2n-7 conditions in 2n variables (13 at n = 10) versus n-7 at degree n. Recovery of alpha is free (alpha = eta^2 + c). The lift buys
   realness and costs more conditions. Scoped to sparse y^m = sextic engines.
7. **Smallest n.** Nonreal root: n = 9 closed (existing). n = 10 is the first open case: it closes if a rational tau with
   p_1 = p_2 = p_3 = 0 exists. A circle-method heuristic predicts about H^{9-2-3} = H^4 points of height <= H if local conditions hold [Heuristic]; a Wolfram box
   search on one S_10 example found none up to height 2 (section 5) [Open]. Beyond n = 10 no cited theorem applies.

## 1. Exact requirements (sub-question a)

**Setup.** A drawable rational pair (C1, C2) gives a crossing polynomial N in Q[u], u an affine coordinate of the crossing point.
We need tau in K generating K with N(tau) = 0 (then chi_tau | N).

- **Isolation [Proof].** The root y0 is isolated by `restrict` in the u-window if y0 is a simple real root of N and u is an affine coordinate
  of the plane point (graph abscissa, or x = u^q for a power law). Window bounds can be rational.
- **Rational data constraint [Proof].** If tau has coordinates in a field L of degree d > 1 and N is rational, all conjugates of chi_tau divide N, so
  deg N >= dn unless chi_tau is already rational; the fibre over a rational N is finite, so "tau over L" is a Galois condition (KL contains a root of N),
  not a free choice of a point on a variety. P-valued parameters (power-law scale, affine entries, affine images of a fixed rational sextic) give N with F_{<n}
  coefficients, but only touch the 5-dimensional affine orbit of a graph; a sextic's 2 rational invariants stay rational (G2).
- **Sparse family, exact shape.** Power law y = c x^{p/q} (x > 0) crossed with y = G(x), G rational of degree <= 6: x = u^q gives
  N(u) = G(u^q) - c u^p, support {0, q, ..., 6q} union {p}, F = 8 (7 if q | p). Rational shifts and shears give the same set of N [Proof]. The overshoot
  condition is: **1, tau^q, ..., tau^{6q}, tau^p are Q-linearly dependent in K** (8 vectors in n dimensions), a Porteous locus of codimension n-7, degree the
  complete symmetric function h_{n-7} of the column degrees (0, q, ..., 6q, p). For p = n, q = 1 these are e_1 = ... = e_{n-7} = 0, equivalently
  p_1 = ... = p_{n-7} = 0 (Newton): forms of degrees 1, 2, ..., n-7. For p = m > n they are the vanishing of the coefficients of t^{n-1}, ..., t^7 in t^m mod chi_tau.
- **Gap/Descartes [Proof, N4].** Totally real q needs all gaps of the support <= 2, impossible for `y^m = sextic`; only odd/even-type supports (F = 8, root capacity 13)
  serve totally real q, and only for n <= 13.
- **Twisted families.** Parabola image x sextic graph: N = Q(u) - G(P(u)), P, Q quadratics: F = 9 [Wolfram], conditions n-8 (n = 10: 2).
  Graph x transposed graph: a rational affine image (a1 u + a2 H + a0, b1 u + b2 H + b0) of y = H(x) meets Y = G(X) where b1 u + b2 H + b0 = G(a1 u + a2 H + a0).
  Put A := a1 u + a2 H + a0. Then b1 u + b2 H + b0 = lambda A + mu u + nu, so N = mu u - (G - lambda X - nu)(A(u)) [Proof, algebra]: the F = 13 family, degree 36,
  cofactor rho of degree 36-n. Unknowns 7 + 7 + 1 + (37-n) - 2 (X scale/shift redundancy) against 37 equations: nonzero solutions require n <= 12 [Proof, count].
- **Shape of W for F = 13 [Proof].** Fix sigma in K and let tau range over Q[sigma]_{<=6}; the condition sigma in span(1, tau, ..., tau^6) has codimension n-7 in the
  P^5 of shapes, and the trivial point tau = sigma (N identically 0) is always on it. Expected dimension 12-n: threefold at n = 9, curve at n = 11, points at n = 12.
- **Count versus n.** c(n) = n+1-F with F = 8, 9, 13 for the three families; G2's offset towers give F = O(log D). No catalogue family has c(n) bounded [Proof for the
  families listed, Heuristic beyond].

## 2. Forms in many variables (sub-question b)

Citations as retrieved:
- Meyer: indefinite integral quadratic forms in >= 5 variables are isotropic [Cited: Serre, A Course in Arithmetic, Ch. IV; used in `Nonic/NonicTschirnhaus.lean`].
- Birch 1962, Proc. Roy. Soc. London Ser. A 265, 245-263: n > B + R(R+1)(D-1)2^{D-1} for R forms of degree D [Cited; inequality quoted as (1.2) in Browning-Heath-Brown].
- **Browning, Heath-Brown, "Forms in many variables and differing degrees", J. Eur. Math. Soc. 19 (2017) 357-394, arXiv:1403.5937.** Cor 1.3 (mixed degrees; conclusion for
  n > B + n_0, n_0 built from t_d = sum_{k>=d} 2^{k-1}(k-1) r_k). **Cor 1.8**: nonsingular pair of degrees D > E >= 2: asymptotic formula for n > (2+E)(D-1)2^{D-1} + E 2^{E-1}; for
  (quadric, cubic) n >= 37 [Cited, arXiv HTML v2].
- **Browning, Dietmann, Heath-Brown, "Rational points on intersections of cubic and quadric hypersurfaces", J. Inst. Math. Jussieu 14 (2015) 703-749, arXiv:1309.0147**: Hasse
  principle for smooth quadric-cubic complete intersections; the threshold n >= 29 is as reported in Glas (arXiv:2306.02718) [secondary; PDF unreadable here: confirm before quoting].
- Heath-Brown, "Cubic forms in ten variables", Proc. London Math. Soc. (1983): nonsingular cubic over Q in >= 10 variables has a nontrivial zero [Cited via secondary sources].
  Heath-Brown, "Cubic forms in 14 variables", Invent. Math. 170 (2007): any cubic form in >= 14 variables [Cited via secondary sources]. Pleasants: cubic forms in >= 16 variables over any
  number field [secondary]. I found no Dietmann paper on quadric+cubic beyond BDH.

**Which conditions can rational tau meet?**
- A quadric (n = 9): yes when s >= 1 (Meyer). [Existing.]
- A cubic alone: nonsingular, >= 10 variables over Q (odd degree gives real points; p-adic solvability is part of the theorem). Not applicable: p_2 and p_3 occur together.
- Quadric + cubic (n = 10, 9 trace-zero variables): cited thresholds 29 / 37 versus 9. After restricting to a maximal rational isotropic subspace U of {p_2 = 0} (dim <= floor(9/2) = 4,
  and <= s over R) the cubic lives on <= 4 variables, far below 10 [Proof, arithmetic]. Hilbert's route (cubic surface in a 4-dim isotropic space, then a line) needs s >= 4 (G1 R3).
- n = 11 (degrees 2, 3, 4), n = 12 (2, 3, 4, 5): no applicable theorem found. Equal-degree Birch proxy R(R+1)(D-1)2^{D-1} = 288 (R = 3, D = 4) and 1280 (R = 4, D = 5) against 10 and 11 variables.
- **Failure for large n [Proof, scoped].** For fixed F, c(n) = n+1-F >= n-12 forms in n variables, and 2c(c+1) > n for c >= 3: these hypotheses fail for every fixed engine and every n >= 11.
  The theorems count solutions of complete intersections of codimension far below the number of variables; here the codimension is n minus a constant.
- **Number field L.** Weil restriction turns c forms in n variables into dc forms in dn variables: the Birch constant grows quadratically in dc, the variable count linearly: no gain.
  Complex places of L make the real condition vacuous there, but L must embed in R, and at that embedding the form on K tensor R is the original (definite iff q totally real) [Proof].
- **p-adic conditions** are automatic in the many-variables regime; in the small regime I checked none [Open].

## 3. Smallest n (sub-question c)

| n | engine (F) | conditions | q with a nonreal root | totally real q |
|---|---|---|---|---|
| 9 | y^9 = sextic (8) | p_1 = p_2 = 0 | **closed** (Meyer, existing) | p_2 > 0: shape impossible; odd engine 2 conditions, degree 1428 (N2) |
| 10 | y^10 = sextic (8) | p_1, p_2, p_3 = 0 | quadric + cubic in 9 variables: [Open]; heuristic says solvable | impossible; odd engine: 3 conditions |
| 10 | parabola-twisted (9) | 2, degrees not computed | [Open] | support not checked |
| 10-12 | graph x transposed graph (13) | 0 over C, nonlinear | [Open]: rational point of incidence variety | no p_2 obstruction visible |
| 11 | y^11 = sextic | p_1..p_4 = 0 | no theorem applies | impossible |
| 12 | y^12 = sextic | p_1..p_5 = 0 | no theorem applies | impossible |
| >= 13 | bounded-F engines | n+1-F | no theorem applies | F = 8 odd engine capacity exceeded for n >= 14 |

The arithmetic route as stated (Meyer plus Birch-type, sparse sextic engine) closes n = 9 and no more. n = 10 is the first open case and needs a Hasse principle for a
quadric-cubic pair in 9 variables. Beyond that one needs either (i) a method for rational points on determinantal loci of dimension F-2 and codimension n+1-F (a rational parametrization of W,
or a way to solve the mutual-polynomial condition for the F = 13 family), or (ii) a drawable family with F >= n+1 and *linear* cofactor problem; the catalogue has none (rational degree-8 graphs would give
F = 10, excluded by the user decision).

## 4. Totally real q (sub-question d)

- p_2 > 0 for every real tau [Proof]. Sparse `y^m = sextic` engines are unavailable; odd-type engines (F = 8, capacity 13) serve n <= 13 and cost n-7 conditions with no quadric and no Meyer.
- **Square lift.** g(y) = f(y^2 + c) is irreducible when alpha - c is a non-square in Q(alpha) [Proof, standard]. Choosing c between the two largest roots gives 2 real roots and n-1 conjugate pairs
  [Wolfram, n = 10: signature (11, 9), irreducible, c = 9/2]. Meyer then gives rational tau with p_1 = p_2 = 0. Recovery needs no induction (finding 1). Cost: 2n-7 conditions in 2n variables for a sparse
  engine versus n-7 in n; at n = 10, 13 versus 3 (odd engine). [Proof of counts, scoped.] The lift does remove the realness obstruction, which the generic y^m engines otherwise have.
- With the F = 13 engine at degree 2n: 2n+1-13 = 2n-12 conditions (n = 10: 8), not unconditional.
- Lifts q(g(y)) with deg g >= 3 multiply the degree further for the same gain [Heuristic: conditions scale with the lifted degree].
- Whether Tschirnhaus elements for g can be chosen odd in y (so as not to factor through f) is G1's open question [Open].

## 5. Wolfram experiments (n = 10, 11)

All in the Wolfram kernel.
- **F counts** (Jacobian rank at a random integer point): graph x transposed graph (degree 36): 13; parabola image x sextic graph (degree 12): 9.
- **S_10 example** f10 = x^10 - 3x^9 + 2x^7 - 5x^4 + x^3 + 4x - 7: irreducible, 2 real roots, trace-form signature (6, 4) so s = 4 and Meyer applies to p_2. (A first test polynomial
  x^10 - x - 1 is not generic: it has the engine shape, tau = x gives p_1 = p_2 = p_3 = 0 trivially.)
- **Box search for p_1 = p_2 = p_3 = 0 on f10:** tau = sum c_i (10 x^i - Tr x^i), i = 1..9 (trace zero by construction), exact integer power sums t_m, p_2 = c T2 c, p_3 = T3(c,c,c).
  |c_i| <= 1: 9841 vectors, 0 on the quadric. |c_i| <= 2: 488281 vectors, **1 on the quadric, 0 on quadric and cubic**. [Wolfram] No small rational tau at this height. The quadric alone is already
  sparse in the box (very eccentric form), so this does not test the circle-method prediction; a real search needs Meyer's explicit isotropic vector plus lattice reduction. Not done.
- **Totally real n = 10 control:** x^10 - 55x^8 + 1001x^6 - 7007x^4 + 15015x^2 - 6435 + 3x: signature (10, 0), definite.
- **Square lift** of that polynomial at c = 9/2: irreducible degree 20, 2 real roots, signature (11, 9).
- **n = 11:** my candidate was reducible; not searched. Needs three forms (degrees 2, 3, 4) in 10 variables. [Open, not run.]

## Other things noticed

- The Lean nonic engine takes tau = phi o psi with degrees <= 6; the free-recovery lemma (Euclid in F[x]) lets tau range over all trace-zero coordinates (8 variables for Meyer instead of 6) and could simplify the nonic proof.
- A rational affine image of a sextic graph crossing a sextic graph collapses to {mu u - Gt(A(u))}; a copy rotated by any rational rotation gives the same family after a rational change of coordinates [Proof, section 1].
- G2 and N2 count only linear sparse families. The F = 13 family is the first with F >= n+1 at n = 9..12 using only rational drawable data; whether the cofactor can be produced is the real question.
- Unverified citations: BDH threshold 29 (via Glas), Lewis p-adic cubic zeros, Heath-Brown 1983/2007 journal details, Pleasants.
