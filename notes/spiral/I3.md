# I3: Archimedean spiral against the transcendental base curves (`exp_two`, `sine`)

Stream I3 of `pptc/PLAN-spiral.md`. Pure mathematics, no Lean edits. Every number below
came from the Wolfram Language evaluator (40 to 60 working digits; Python was not used).
Labels: **[Proof]** argument written here, **[Wolfram]** computed/verified, **[Heuristic]**,
**[Open]**. Classes: **E** elementary, **R** already reachable, **N** new and named,

## Findings summary

1. **Normal form [Proof].** Any affine image of the spiral `θ e^{iθ}` has coordinates
   `X = ρ₁ θ cos(θ−β₁) + c₁`, `Y = ρ₂ θ cos(θ−β₂) + c₂`, and any affine image of
   `y = 2^x` or `y = sin x` is `{L(t, 2^t)}` resp. `{L(t, sin t)}` with `L` affine
   invertible. So every intersection in this stream is one of
   - **exp:** `2^{ρ₁θcos(θ−β₁)+c₁} = ρ₂θcos(θ−β₂)+c₂` (after reparametrizing; sign and
     scale of the exponent and an overall `A`, `D` are absorbed into `ρ, c`);
   - **sine:** `ρ₂θcos(θ−β₂)+c₂ = A sin(ω(ρ₁θcos(θ−β₁)) + φ) + D`.
   
   The simplest members are `θ sinθ = 2^{θ cosθ}` and `θ sinθ = sin(θ cosθ)`. Rotating the
   base curve by an angle is the same as changing `β₁−β₂`-type phases of the spiral
   (rotating a spiral is a phase shift `θ → θ+β`, because `r = θ` rotated by `β` is
   `r = φ−β`), so rotations add nothing beyond the phase `β`. Rank-1 degenerate maps
   (`β₁ = β₂ mod π`, or a `scale` by 0) collapse the spiral to a segment and give an
   elementary (**E**) intersection.
2. **Classification: both families are `?`** [Heuristic]. Each puts a *product* `θ·cosθ`
   inside a second transcendental function (`2^•` or `sin •`). That is outside
   - T1–T6 of `M.md` §2 (one trig/tanh function of an affine function of the unknown);
   - `sheared-sine-intersections.md` §1 (rows 1–4 all have arguments *affine in
     `(t, sin t)`*; here the argument `θ cosθ` is bilinear in `(θ, cosθ)`).
   
   No reduction to a reachable class was found [Heuristic; non-reducibility not proved].
   No named problem was found (searched; see §6).
3. **Exact collapse that does occur [Proof + Wolfram]: sine, matched pitch.** For the
   sine `y = A sin(ωx)` and spiral `r = bθ`, the spiral meets the axis at `x = ±bmπ`, where
   the sine vanishes whenever `ωbm ∈ ℤ`. So `θ = mπ` (all `m` with `ωbm ∈ ℤ`) are
   **exact, elementary roots** (`θ sinθ = sin(θcosθ)` is `0 = 0` at `θ = mπ`). They must be
   excluded with `restrict`; the other roots are the content. With `ω b = 1`, `A = 1`, `φ=0`:
   exactly **one** non-trivial root in `θ ≤ 10π`, `0.759862…`. With sign flipped
   (`θ sinθ = −sin(θcosθ)`) there is **no** non-trivial root up to `10π`.
4. **Large-θ structure [Proof sketch + Wolfram].** For the sine the spiral crosses the
   `x`-axis steeply (`dy/dx ≈ mπ`), so near each `θ = mπ` there is exactly one root,
   `θ_m = mπ + s_m(A sin(ω s_m mπ + φ) + D)/(mπ) + O(m⁻³)`, `s_m = (−1)^m`: two roots per
   turn, leading term elementary. For exp there are two interleaved families per turn:
   `θ_m = mπ − 2^{−mπ}/(mπ)` (m odd; exponentially tiny offset, checked) and
   `θ ≈ π/2 + 2kπ − log₂θ/θ` (Lambert-like, `x = log₂ y` against `y ≈ θ`).
5. **Windows [Wolfram].** In the pure window `θ ∈ (0, 4π]` the base exp case has 4 roots
   (all in range), generic phases `β` also 4; the sine base case has 1 non-trivial root plus
   `π, 2π, 3π, 4π`. All of these are `≤ 4π`, so they sit in the `(0, 4π]` window
   *if* W confirms it. Infinitely many more roots exist beyond (40 roots up to `40π` for
   the base exp case, exactly 2 per turn).
6. **Uniformity [Proof sketch].** Every parameter of the normal form
   (`ρᵢ, βᵢ, cᵢ, A, D, ω, φ`) is realised by `translate_*`, `scale_*`, `rotate` with
   `PConstructible` data (non-whole-degree angles via `scale_x/scale_y` + `rotate`, as
   in `CLAUDE.md`). Given an isolated root, a rational box isolates it, `restrict` cuts both
   curves to it, `inter_x/inter_y` reads `(x, y)` and `θ = √(x²+y²)/b` follows
   (`div`, `mul`, sqrt is constructible). Fixed configuration, windows varied: one
   configuration yields the *infinite* sequences in finding 4. All nonzero-transversality
   checks in §3 pass.
7. **No special parameter choice turns either family into something named** (sections 2 and
   4). Only the pitch/frequency matching of finding 3, designed roots, and the 4th-order
   contact at the origin occur.

## 1. Setup and what "rotating by the spiral's own angle" gives

Spiral `γ(θ) = (θcosθ, θsinθ)`. Writing `z = θe^{iθ}` and `u = Re z`, the sine intersection
is `Im z = A sin(ωu + φ) + D`. A general affine image just changes the two phases.

*Co-rotating frame [Proof].* Rotate by `−θ`: the spiral point becomes `(θ, 0)`. The
condition is "`R_{−θ}(base curve)` contains `(θ,0)`". If the base curve were rotation
invariant (circle) or log-spiral-covariant this would collapse; neither `2^x` nor `sin x`
has that property, so the condition is the same equation. No simplification. In
particular a rotated exponential does **not** become a logarithmic-spiral-like relation:
log-spirals come from *wrapping* (the text warp), not from rotation, and `r = θ` against
`r = ce^{aθ}` is a different (spiral ∩ spiral, stream I4) problem.

*Polar form [Proof].* Spiral `φ = r`; base curve `r sinφ = 2^{r cosφ}` (resp.
`r sinφ = sin(r cosφ)`); put `φ = r = θ`. The nesting `r cosφ` inside the function is
intrinsic.

Transversality: `g'(0.7598…) = 1.068 ≠ 0`; the trivial roots `θ = mπ` have `g'(π) = −π−1`
(not tangent). So `restrict` isolates each. Roots of `(0,4π]` are just the listed entries
`≤ 12.566`.

**Trivial-root mechanism [Proof, Wolfram].** `mπ sin(mπ) − sin(mπ cos(mπ)) = 0` for all
`m` ([Wolfram: FullSimplify for m = 1..6]). In general: spiral `r = bθ` meets the line
`y = 0` at `x = ±bmπ`; the sine `A sin(ωx)` vanishes there iff `ωbm ∈ ℤ`. So the family
`ωb ∈ ℚ` has exact elementary roots (class **E**). If `ωb` is irrational, or `φ ≠ 0`, `D ≠ 0`,
or `β ≠ 0`, no trivial roots, all roots are transcendental-looking.

**Near the origin [Proof + Wolfram].** The spiral is, near the origin,
`y = x² + (5/6)x⁴ + (161/120)x⁶ + (1501/560)x⁸ + …`. A sine `A(1−cos ωx)` with `Aω²/2 = 1`
(tangent to the spiral at the origin; this includes `sin²x` for `ω=2`) differs by
`((10+ω²)/12) x⁴ + O(x⁶)`. So contact at the origin is of order 4 and **never** produces
extra near-origin roots: the near-origin intersection is the (non-window) point `θ = 0`
itself plus perturbation-theory algebraic data, class **E** to every finite order. With a
small offset `D = 1/10` for `y = sin²x`, the roots are `3.1728, 6.2673, 9.4354, 12.5584`:
again one per half-turn near `mπ`, none near the origin.

**Large θ [Proof sketch].** At `θ = mπ+ε`: `y ≈ s mπ ε`, `x ≈ s mπ`, `s = (−1)^m`. The
sine is flat compared with the steep spiral, so one root with
`ε ≈ s(A sin(ωsmπ+φ)+D)/(mπ)`. Check against `φ=π/2` rows: `π+0.2922` (predicted
`π + 1/π = π+0.3183`), `2π + 0.1555` (predicted `1/(2π) = 0.1592`).
If `ω` is irrational the fractional parts of `ωm/2` equidistribute, so the offsets are
dense in `[−(A+|D|)/(mπ), (A+|D|)/(mπ)]`. [Heuristic: equidistribution step only.]

## 5. Is this beyond T1–T6? (structure)

Let `c = cosθ`, `s = sinθ`, `u = θc`. The sine equation is `θ s = A sin(ωu+φ)+D`,
the exp equation is `θ s = A·2^{ku+c}+D`. The unknown `θ` appears (i) as a factor, (ii) in
`s`, `c` (iii) in the argument `u = θc` of the outer function. Compare:

- **T1–T6** (`M.md`): `tan x = λx+μ`, `(λx+μ)tan x = 1`, `tan y + y = k`, `sin x = ±tanh x`,
  `sin y − (y+φ)cos y = c`, `θ tan(θ−β) = b`. One harmonic of an affine function of the
  unknown; *no function composition*.
- **Sheared sine rows** (`sheared-sine-intersections.md` §1): includes composition
  (`sin(t + k sin t)`), but with argument **affine** in `(t, sin t)`.
- **Here**: argument `θ cosθ`, a product.

Consequences: (a) neither dictionary entry contains these equations [Proof, by syntax].
(b) The function `F(θ) = θ sinθ − 2^{θcosθ}` is entire of infinite order
(`Re(θcosθ)` has a `cosh y` factor on `θ = x+iy`); this does not separate it from the
sheared-sine composition rows (`sin(sin t)` is also infinite order), so it is *not* evidence
of independence. (c) The analytic-continuation argument of `sheared-sine-intersections.md`
§3b (for algebraic partners) does not apply, since the partner here is transcendental.
(d) A relation to `tan x = x`-type problems would need `sin` and `cos` of the *same affine
argument* (one harmonic); `θ·cosθ` as an argument does not give that.

So: **class ?**, a new, unnamed family [Heuristic]. A proof of non-reducibility would require
transcendence/Schanuel-type input or an Ax-style argument; not attempted. [Open]

## Other things noticed

- **Trivial roots look non-trivial.** In an automated search the base sine case returns
  five "roots" in `(0, 5π]`, of which four are the exact `θ = mπ`. Any uniformity
  statement must say "after removing the `ωbm ∈ ℤ` roots".
- **Exponentially thin windows.** The exp roots near odd `mπ` are at distance `2^{−mπ}/(mπ)`
  from `mπ`, i.e. `1.5·10⁻⁴` at `m=3` and `10⁻¹⁰` at `m=9`. A `restrict` box can be rational
  but must be this thin; fine for the formal class, hostile for a drawn construction.
- **Lambert W** appears for the exp *wrapped* around the origin (`log spiral ∩ Archimedean`),
  a likely clean `N` for I4. It does not appear here, where the exponent is `θcosθ`
  rather than `θ`.
- **Reflection identity.** Because `sin` is odd, the four reflections of the spiral against
  the sine give only two inequivalent equations (`±θ sinθ = sin(θcosθ)`); for `exp_two` all
  four are different. The `−` sine case has no non-trivial roots to `10π`, an apparent
  asymmetry not understood (the bound `|θ sinθ| ≤ 1` forces the root near `mπ`; the
  local expansion gives `ε = 2(1−smπ)/(mπ)`, order 1, so it falls outside the local regime).
  [Heuristic]
- **Possible stream C hook.** The spiral roots `θ` are themselves `PConstructible`
  (`θ = r`), so `cosθ`, `sinθ` are available and the root can be fed into further constructors.
