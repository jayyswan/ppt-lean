# I2: Archimedean spiral meets polynomial graphs (deg <= 6), power laws, cubic Beziers

Stream I2 of `pptc/PLAN-spiral.md`. No Lean edits. All numerics are Wolfram Language (50-digit
working precision, residuals <= 1e-40 unless noted); Python was not used. Labels: [Proof],
[Wolfram], [Heuristic], [Open]. "Roots in window" means theta in (0, 4 pi] (plan §0, stream W
still confirming); every root listed is inside it. Conics (deg <= 2) are I1's except the parabola
`y = k x^2`, settled here.

## Findings summary

1. **Why this is hard [Proof].** The spiral coordinates are `x = theta cos theta`,
   `y = theta sin theta`: *products* of theta with a harmonic. An algebraic curve `F = 0` of
   degree d gives `sum_{j<=d} theta^j h_j(theta)` with `h_j` in the span of `e^{ik theta}`,
   `|k| <= j`, `k = j mod 2` (checked symbolically for a general cubic [Wolfram]: harmonics
   {1}, {2}(+const), {1,3} at theta^1, theta^2, theta^3). Compare the sheared-sine constraint
   (`sheared-sine-intersections.md` §1): one harmonic, theta to the first power. So a spiral
   meets a base curve in a "reachable" way (R) only when the equation collapses to
   `theta^p * (single harmonic) = const` or to `Phi(theta, sin theta) = 0` with the algebraic
   curve `Phi = 0` itself drawable.
2. **Parabola `y = k x^2` [Wolfram + Proof]: class `?`, unnamed, not R.**
   `sin theta = k theta cos^2 theta`, equivalently `theta = tan theta sec theta / k`, i.e.
   `sec'(theta) = k theta` (critical point of `sec theta - k theta^2/2`). At k = 1 this is
   `x = tan x sec x`. It collapses to **one** trig function: `theta (1 - s^2) k = s`, `s = sin theta`,
   so it is the sine graph meeting the cubic `C_k: k x (1 - y^2) = y`. `C_k` has three points at
   infinity, a node at `(1:0:0)` (tangents `y = +-1`), is rational but **not polynomially
   parametrised**, and is none of: poly graph, power law, ellipse, Bezier. So the direct route is
   closed [Proof, asymptote/point-at-infinity argument as in sheared-sine §3d]. Whether *another*
   route reaches it is [Open]. First roots (k=1): 2.2152214431263645714504004781459598,
   7.4928387844959373609752677665590512, 8.1995631489076686278078457653947772.
3. **Even / odd structure of aligned graphs `y = P(x)` [Proof].**
   - `P` even (only `x^0, x^2, x^4, x^6`): `theta s = sum a_{2j} theta^{2j} (1-s^2)^j`, a polynomial
     `Phi(theta, sin theta) = 0` (single trig function, sine meets a quartic-to-degree-13 algebraic
     curve; never drawable for j >= 1 except the degenerate cases below).
   - `P` odd (`P = x E(x^2)`): `tan theta = E(theta^2 cos^2 theta)`; squaring gives a polynomial in
     `(theta, cos 2 theta)` (one harmonic of the *doubled* angle, sign-spurious roots removed by
     `restrict`).
   - Mixed parity: genuinely both `c` and `s` with theta-polynomial weights: two harmonics (1 and
     2 already for `x + x^2`): **?**.
4. **Power laws `y = a x^b` (x>0) [Proof + Wolfram].** With `e = 1 - b`:
   `tan theta (theta cos theta)^e = a`. Reduction by b:
   - b = 1: `tan theta = a`: **E**.
   - b = 0: `theta sin theta = a` (hyperbola meets sine): **R**.
   - b = -1: `theta^2 sin 2 theta = 2a`, i.e. with `u = 2 theta`, `sin u = 8a/u^2`: sine meets
     `power_law` b = -2: **R**. (Hyperbola `y = a/x` against the spiral is a sine-meets-power-law
     problem.) These three (b = 1, 0, -1) are the **only** b in which the equation is a single
     harmonic times a power of theta [Proof: need `sin cos^{e-1}` single harmonic, e in {0,1,2}].
   - b = 2 (parabola, x>0 half): item 2, **?**. b = 1/2 (sideways parabola): `theta sin^2 theta = a^2 cos theta`,
     `theta = a^2 c/(1-c^2)`, the *same cubic* `C_{a^2}` against the cosine: **?** (same class).
   - b = 3: `tan theta = a theta^2 cos^2 theta`, odd class. b = -2: `theta^3 sin theta cos^2 theta =
     theta^3 (s - s^3) = a` (harmonics 1,3): **?**. b = -1/2: `theta^3 sin^2 theta cos theta = a^2`:
     **?**. Rational b = p/q: algebraic in `(theta, s, c)`, **?**.
   - Windows: x>0 forces cos>0; with a>0 also sin>0, so roots lie in `(2 pi n, 2 pi n + pi/2)`;
     reflections (`scale_x(-1)`, `scale_y(-1)`) reach the other quadrants. Within (0, 4 pi]: n = 0, 1 only
     (a>0), or `(3pi/2, 2pi)`, `(7pi/2, 4pi)` (a<0).
5. **Cubic Beziers [Proof + Wolfram].** Up to affine maps a non-degenerate cubic Bezier is one of
   four shapes: cubic parabola `y = x^3` (it is a graph already), cuspidal `y^2 = x^3`, nodal loop
   `y^2 = x^2 (x+1)`, and the "solitary" `y^2 = x^2 (x-1)` (param `x = 1+t^2`, `y = t+t^3`,
   isolated point never drawn). The Bezier adds, over graphs: curves that are not functions of x
   (loop, cusp, vertical tangents), and an implicit cubic with *three* harmonics. With the
   singular point at the spiral centre the equation collapses to **one** trig function:
   `y^2 = x^2 (x+m)`  =>  `theta cos^3 theta + (m+1) cos^2 theta = 1`  (m = -1 is the solitary
   curve). **At m = -1 it is `cos theta = theta^{-1/3}`: sine meets a power law (b = -1/3) after a
   quarter-period shift: R.** For m != -1 (loop m = 1, cusp m = 0) it is cosine meeting the
   Laurent graph `x = y^{-3} - (m+1) y^{-1}`: **?**, not a single base curve. Generic position
   (node away from centre, tilted, non-orthogonal affine image) gives the full 1-2-3-harmonic
   equation: **?** (Heuristic).
6. **Negatives.** No uniform route from these families to `tan x = x` or the goat equation: the
   aligned equations contain `tan theta = (power of theta)*(trig)`-type terms only through
   items 3-5; the odd-graph class `tan theta = E(theta^2 cos^2 theta)` never gives `tan x = x`
   itself (E would need `theta` not `theta^2 c^2`). The only elementary-collapse cases are lines
   (I1) and the b = 0, -1 power laws and the solitary Bezier.

Notes on the table: roots with x < 0 are legitimate for full poly graphs but only the x>0 branch for
power laws. The spiral side has further freedom (shift `r = theta + beta` is a rotation of the
graph, giving e.g. the parabola family `sin phi = k (phi + beta) cos^2 phi`, two parameters
(k, beta); `scale_x != scale_y`; centre translation); none of those were enumerated.
Squared forms (odd class, nodal/cusp collapse) can contain sign-spurious roots; restrict removes them.

## What the Bezier adds over a polynomial graph

- Non-graph shapes: cusp, loop, solitary-branch, vertical tangents. Graph degree-3 is only the
  cubic-parabola type.
- With the singular point at the spiral centre, one-parameter (m) collapse to `Phi(theta, cos
  theta)` with Laurent form, which graphs cannot produce, and the single R case m = -1 (the
  solitary curve), which graphs cannot produce either.
- Honest count [Heuristic]: control points give 8 coordinates minus 2 for reparametrisation = 6
  parameters, but up to the *spiral's* affine freedom there are only 4 curve shapes, so the
  "two-parameter" richness lives in the position of the singular point relative to the spiral
  centre (2 parameters) plus tilt/shear. This is stated, not exhaustively classified.

## Other things noticed

- The sign table for power laws: x>0 and a>0 confine roots to `(0, pi/2)` and `(2pi, 5pi/2)` inside
  (0, 4 pi]; only two roots per equation is typical there.
- `y = x^2` parabola roots coincide with the b=2 power law only on the x>0 half (7.4928...).
- Semicubical parabola `y = x^{3/2}` and the cusp Bezier give identical roots (0.617001...) as
  expected; cross-check passed to 30 digits.
- The collapse "node at the spiral centre => `theta c^3 + (m+1) c^2 = 1`" is a cheap way to
  generate one-trig-function equations with nontrivial theta-dependence; the sheared-sine note's
  asymptote argument (§3d) can be reused to show no base curve contains `C_k`.
