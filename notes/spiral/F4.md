# F4: can the spiral's "?" classes be proved non-reducible?

Stream F4 of `pptc/PLAN-spiral.md` section 4. Labels: **[Proof]** paper argument (relies only on the
cited theorems), **[Wolfram]** computed with the Wolfram evaluator (no Python), **[Heuristic]**,
**[Open]**. No Lean was touched.

## 0. Findings summary

1. **The statement is now precise** (section 1). "Not reducible" means: no *regular uniform one-step
   competitor* (RU1). That is one intersection of two spiral-free curves, each depending on the family
   parameter only through algebraic data, whose intersection point determines the root.
2. **Parabola class `sin th = k th cos^2 th` (P).** Partial theorem [Proof, using Ax-Schanuel]. In the
   tower class T of R3 (algebraic, exp-type, trig-type curves, closed under affine maps, restrict,
   **offset**, arcs):
   - algebraic ∩ algebraic, and exp-type ∩ algebraic, are impossible;
   - exp ∩ exp and exp ∩ trig are impossible (modulo the parallel-drift degeneracy, 5.4);
   - trig-type ∩ algebraic works **iff** the algebraic partner contains an explicit rational curve `D`
     (for the natural choice, the cubic `k x (1 - y^2) = y`). This is the sheared-sine criterion of
     `sheared-sine-intersections.md` section 3b, and it is the only surviving case besides 5.4/5.5.
   - For base curves under affine maps (no offsets) the surviving case is closed for the natural phase
     `(r, c) = (1, 0)` and Wolfram-checked non-conic for all sampled `(r, c)`. For general `(r, c)` it is
     [Open]. With offset partners it is [Open] (the gap of `sheared-sine-intersections.md` 3e).
3. **Generic conic class (G).** Same reduction on any one-parameter slice (a uniform competitor restricts
   to a slice). New fact: the curve `W` is **elliptic (genus 1)**. So for the natural competitor
   (`t = th`, no phase) `D` is birational to `W`, hence genus 1, and **no rational base curve contains
   it** [Proof + Wolfram]. Other `(r, c)` and offset partners: [Open].
4. **Exp class `th sin(th - beta) = 2^{th cos(th - beta)}` (X).** Strongest result. Here `th` and
   `e^{i th}` stay algebraically independent over the parameter field, so every competitor needs
   **two** transcendental atoms. The tower cases are then killed by a rigidity computation: no RU1
   competitor exists in T, offsets included [Proof, except 5.4 and the hypotheses 1.4].
5. **Approaches that fail**, with reasons (section 6): inverse-function monodromy / branch-point
   counting (R3 style), root density per turn, asymptotic root locations.

## 1. Precise statements

### 1.1 Competitors
`T` is the tower class of `notes/offset-inversion/R3-separation.md` section 1 (R3 Theorem 1.1
[Proof, cited]). Every curve drawable **without the spiral** (base curves, `translate`, `scale`,
`rotate`, `restrict`, `offset`, and `arc_of_length` arcs, which are sub-arcs of curves already in T) is,
up to restriction, one of
- **(A)** a subset of a real algebraic curve;
- **(E)** `gamma(t) = (a t + A1(e^{l t}), b t + A2(e^{l t}))`, `l` real, `A1, A2` algebraic;
- **(Tr)** the same with `z = e^{i t}` (so `A_j` is algebraic in `(sin t, cos t)`, bounded).

`box_xmax/ymax` and `arc_length` produce numbers, not curves, so using them is a depth-2 step and is
excluded here.

### 1.2 Families
A *level-set family* is `Lambda_g = { th : g(th, e^{i th}) = k }`, `g` a nonconstant rational function and
`k` the P-constructible parameter (the parameter enters as the level):
- **P:** `g = sin th / (th cos^2 th)`, parameter `k`.
- **G (slice):** `g = -[Re(A th^2 e^{2i th} + B th e^{i th}) + m th^2]`, parameter `f`, with `A, B, m`
  fixed and generic. Uniformity in all five parameters is stronger than uniformity on this slice, so a
  slice result implies the full-family result.
- **X:** the I3 family, parameter the phase `beta`, `k = e^{i beta}`.

### 1.3 Uniform one-step competitor (RU1)
Let `K0` be the algebraic closure of `C(input data)` (for P, G: `C(k)`; for X: `C(beta, e^{i beta})`),
`C` any constants. An RU1 competitor for a family is a pair `S_k, T_k` in T such that:
1. all affine / offset / drift data are in `K0` (a finite field-operation construction from the inputs);
2. the intersection point `p(k) = (x, y)` lies on both curves;
3. the root is read out algebraically: `th*(k)` is algebraic over `K0(x, y)`.

This is the "uniform convention" of `sheared-sine-intersections.md` section 3, generalised from "constant
parameters" to "algebraic dependence on the family parameter". Restricting to one step means the data
are not themselves outputs of an earlier transcendental construction.

### 1.4 Regularity (hypothesis)
The intersection is **transversal** on a `k`-interval. The P-constructible parameters are countable, so
identities are first obtained on a dense set. Transversality plus uniqueness (`inter_x` demands exactly
one point) extends them by the implicit function theorem to an interval, and `p(k)` is analytic. An
isolated tangential intersection persisting along a whole interval is not covered [Open]; it is a
codimension-1 phenomenon, but I did not rule it out.

### 1.5 Tool: Ax-Schanuel (1971)
If `y_1, ..., y_n` are analytic germs, Q-linearly independent modulo constants and not all constant,
then `tr.deg_C C(y, e^y) >= n + rank(dy/dk)`; in one variable the rank is 1. Cited, not re-proved.

### 1.6 What is claimed

| id | statement | status |
|---|---|---|
| T-P | no RU1 competitor for P except trig-type ∩ algebraic with `T ⊇ D`, and cases 5.4 / 5.5 | [Proof], sections 3-4 |
| T-P0 | base-affine competitors, natural phase `(r, c) = (1, 0)`: none | [Proof + Wolfram] |
| T-G | G, base-affine competitor with `t = th`: none | [Proof + Wolfram] |
| T-X | no RU1 competitor for X in T | [Proof] modulo 5.4 |
| N-1 | P, general `(r, c)`, hyperbola / negative-power-law partner | [Open] (samples: no conic) |
| N-2 | P, G against *offset* partners (algebraic or tower) | [Open] |

## 2. Preliminaries on the three families

### 2.1 P
With `u = e^{i th}`, a root satisfies `th = R_k(u) = 2u(u^2-1) / (i k (u^2+1)^2)` [Wolfram]. So the curve
`W_k = {Phi_k(th, u) = 0}` is **rational** (parametrised by `u`); `K0(th, u)` has transcendence degree 1
over `K0 = C(k)^alg`; `R_k` has double poles at `u = ±i`.
- `th` is transcendental over `K0` [Proof]: otherwise `u` is algebraic too (degree-4 equation), so
  `tr.deg_C C(th, u) <= 1`, contradicting Ax (`n = 1`, rank 1: `>= 2`).
- Real roots, `k = 1` [Wolfram]: 2.2152, 7.4928, 8.1996, 13.8703, 14.3991, 20.1988, 20.6396, ...
  Asymptotically `th_n = pi/2 + 2 n pi ∓ 1/sqrt(k th_n)` (matches to 3-4 digits at `th ~ 14-58`): two
  roots per turn.

### 2.2 G (slice)
`Phi = a2 th^2 + a1 th + f` with `a2 = m + (A u^2 + conj(A) u^{-2})/2` and `a1 = (B u + conj(B)/u)/2`:
**quadratic in `th`**. For `A = 1 - 2i, B = 4, m = 3` the numerator of the discriminant is
`2(2 - (1+2i) f + 4u^2 - 6 f u^2 + 2u^4 - (1-2i) f u^4)`, a quartic in `u`; its `u`-discriminant is
`-262144 i (f-2)^2 f (-2+(1+2i)f)(-2i+(2+i)f)`, nonzero for generic `f` [Wolfram]. So `W` is
`w^2 = (squarefree quartic)`: **genus 1**. Compare P: genus 0.
Also `Phi` is linear in `cos th` (the `cos^2` terms cancel via `cos 2th = 1 - 2 sin^2 th`), so
`cos th ∈ K0(th, sin th)` and `K0(W) = K0(th, sin th)` [Proof].

### 2.3 X
`ell := ln2 * th cos(th - beta)`, `V := e^{ell}`. The equation says `V = th (u/k - k/u)/(2i)` with
`k = e^{i beta}`, while `V = e^{ell}` and `ell = (ln2/2) th (u/k + k/u)`.
- `i th` and `ell` are Q-linearly independent modulo `C` [Proof]: `ell` is real and `i th` imaginary, so
  a relation forces `ell` constant; but `th cos(th - beta)` is not constant in `beta`.
- Ax on `(i th, ell)` gives `tr.deg_C C(k, th, u) >= 3`. So **`th, u` are algebraically independent over
  `K0`** [Proof] (contrast P, G). The family is genuinely "two-dimensional".

## 3. The reduction lemmas

Notation: `S(t)` carries `z = e^{l t}`, `T(s)` carries `w = e^{m s}`; `F = K0(t, z, s, w, th, u)`,
`d = tr.deg_{K0} F`. Types: E (`l` real), Tr (`l = i`), A (algebraic partner, no parameter).

**Counting [Proof].** `F` is generated over `K0` by the parameters and atoms, and the two coordinate
equations (E1, E2) are algebraic relations over `K0`. So `d <= 2` if both curves are transcendental,
`d <= 1` if one is, `d = 0` if neither. Ax on `(l t, m s, i th)` (those present) gives `dim_Q L <= d`,
where `L` is their Q-span modulo `C`.

**Real/imaginary lemma [Proof].** `l t`, `m s` of type E are real-valued; `i th` and type-Tr `i t` are
imaginary. A Q-relation `n_3 i th + n_1 l t + ... = c` splits into real and imaginary parts. So E-type
parameters never occur in a relation together with `th` (since `th` is nonconstant).

**Constant-parameter lemma [Proof].** If an E-type parameter `t` is constant in `k`, then `z` is
constant and `S(t_0) ∈ K0`, so `p ∈ K0` and `th` is algebraic over `K0`: a contradiction (section 2).

### 3.1 P: the cases
- **(A, A):** `d = 0 < dim L = 1`. Impossible [Proof].
- **(E, A):** `d <= 1`, so `i th` and `l t` are dependent. By the real/imaginary lemma `l t` is constant;
  by the constant lemma this is impossible [Proof].
- **(Tr, A):** `t = r th + c`, `r in Q*`, `c` real. Then `Q_k(S_k(r th + c)) = 0` at the generic point
  of `W_k`, so **`T_k ⊇ D_k`**, the Zariski closure of the image of `W_k` (or of its `q`-fold cover
  `v^q = e^{iqc} u^p` when `r = p/q`) under `Psi = (a t + A1(v), b t + A2(v))` [Proof]. This is the
  sheared-sine 3b criterion. The places of `D` are listed in 4.2.
- **(E, E):** the real/imaginary lemma gives `n_3 = 0`; Ax then needs `dim span(l t, m s) <= 1` (since
  `dim L = 1 + dim span <= d <= 2`), i.e. `s = r t + c` (or one is constant, excluded). Then E1 and E2 are
  two relations on `(t, z)`. If independent, `t` is algebraic over `K0`, hence `z` too, contradicting Ax
  (`tr.deg_C C(l t, z) >= 2`). If dependent, `d = 1 < dim L = 2`. Impossible [Proof].
- **(E, Tr):** the real part kills the E-coefficient, leaving `s = r' th + c'`. Then `p = T(s) ∈
  K0(th, u)^alg`, and `S(t) = p` makes `z` algebraic over `K0(th, u)` (through `b A1 - a A2`, a
  nonconstant algebraic function of `z` unless `S` is a line), hence `t` too. So `d = 1` while `dim L = 2`.
  Impossible [Proof]. (If `S` is a line, treat it as an (A) partner and use (Tr, A).)
- **(Tr, Tr), `dim L = 1`:** `t = r th + c`, `s = r' th + c'`, so the two curves must agree as algebraic
  maps on the rational curve `W` (the coincidence is an identity of rational functions of `u`).
  *Pole argument*, for affine images of the sine graph: `(a r - a' r') R_k(u)` has double poles at
  `u = ±i`, while the `sin(r th + c)` terms have poles only at `u = 0, infinity`. So `a r = a' r'`,
  `b r = b' r'`, and the periodic parts must also agree: `S` and `T` are reparametrised translates, so
  they share a whole arc, contradicting "exactly one intersection point" [Proof, base-affine
  competitors]. For offset-type `A_j`, the argument needs `A_j` regular at `v_infty`: [Open] (5.5).
- **(Tr, Tr), `dim L = 2`:** `th = F(z) + G(w)` with `F, G` algebraic (solve E1, E2 linearly, `Delta != 0`)
  and `u = c_0 z^a w^b`. Then `F(z) + G(w) = R_k(c_0 z^a w^b)` for independent `z, w` (here `d = 2`).
  Apply `z d/dz` and `w d/dw`: `zF'(z)/a = wG'(w)/b = v R_k'(v)`, so `v R_k'(v)` is constant, so `R_k` has a
  logarithm: contradiction with rationality [Proof]. If `a = 0` or `b = 0`, then `t` is an algebraic
  function of `z` alone, and `z = e^{l t}` gives `1/z = l f'(z)`, so `f = (1/l) log z` is not algebraic.

### 3.2 G (slice)
`W` is elliptic, so `th` is not a rational function of `u`; the pole argument does not apply as stated.
The other cases use only `tr.deg`, the real/imaginary lemma and rigidity identities, so (A, A), (E, A),
(E, E), (E, Tr) and (Tr, Tr) with `dim L = 2` go through verbatim [Proof].
- (Tr, A): `T_k ⊇ D_k`, the image of `W_k` (or of its cover).
- (Tr, Tr), `dim L = 1`: needs the coincidence `Psi_S = Psi_T` on a genus-1 curve. [Heuristic]: the
  analogous pole argument (`th` has poles at the zeros of `a2`, the sine terms only above `u = 0,
  infinity`) gives the same conclusion; not written out.

### 3.3 X
Here `d = tr.deg_{K0} K0(th, u) = 2` is forced.
- **(A, A), (E, A), (Tr, A):** `d <= 1 < 2`. Impossible [Proof]. This is stronger than for P: **no
  algebraic partner can work at all.**
- **Both transcendental:** `d = 2`, `dim L <= 2`, and `i th, ell` are already independent. So `l t` and
  `m s` lie in `Q i th + Q ell + C`. By the real/imaginary lemma, E-type parameters satisfy
  `l t = a_2 ell + c_1`, Tr-type ones `s = b_1 th + c_2`.
  - **(E, E):** `t, s` are both Q-multiples of `ell`, so `s = r t + c`; the (E, E) argument of 3.1
    applies [Proof].
  - **(Tr, Tr):** `t = r th + c`, `s = r' th + c'`. As `th, u` are algebraically independent, E1 and E2
    are polynomial identities in `(th, u)`. The coefficient of `th` must vanish (`th` is transcendental
    over `K0(u)^alg`): `a r = a' r'`, `b r = b' r'`. Then `A_j(c u^r) - A_j'(c' u^{r'})` is constant, so
    `S(t) = T(s(t))` identically: the curves share an arc. Impossible [Proof]. This works for arbitrary
    algebraic `A_j`, **offsets included**.
  - **(E, Tr):** `z = c V^{a_2}`, `w = c'' u^{b_1}`. E1 reads
    `A1(c (th g(u))^{a_2}) = th (a' b_1 - a a_2' h(u)) + A1'(c'' u^{b_1}) + const`,
    with `g = u/k - k/u` and `h = u/k + k/u`. Fix `u`, vary `th`: `A1` composed with a monomial is linear in
    `th`, so `A1(X) = kappa X^{1/a_2} + const`, and the slope `a' b_1 - a a_2' h(u)` equals `kappa g(u)`.
    Since `1, u, 1/u` are linearly independent: `a a_2' = 0` and `a' b_1 = 0`. Hence `a = a' = 0`, and
    likewise `b = b' = 0`: both drifts vanish, both curves are algebraic, contradicting the first bullet
    [Proof].

## 4. The surviving case for P and G: trig-type ∩ algebraic

### 4.1 Fixed-`k` form of the criterion (the sheared-sine argument) [Proof]
Take `S` the plain sine graph and `T = {Q_k = 0}` algebraic. At every large root with angle
`v = th_n mod 2 pi`, the root is an explicit function `th_n = sin v / (k cos^2 v)`. So
`Q_k(sin v/(k cos^2 v), sin v)` is analytic in `v` near `pi/2` after clearing poles and vanishes on the
accumulating sequence `v_n -> pi/2`. Hence it vanishes identically: `Q_k ⊇ { k x (1 - y^2) = y }`. This is
the Ax criterion for `r = 1, c = 0`, obtained without Ax and with `k` fixed.

### 4.2 Places of `D`
`D` is parametrised by `u` (or `sigma`, with `u = a sigma^q`, `v = b sigma^p`). With
`S = (a t + gamma_1 sin t, b t + gamma_2 sin t)`:
- poles at `u = ±i` (double): direction `(a : b)`, with a finite asymptote offset `~ sin t_infty`;
- poles at `u = 0, infinity`: direction `(gamma_1 : gamma_2)`.
The total pole order of a generic linear form is `4q + 2|p|`, so `deg D * e = 4q + 2|p|`, `e` the degree of
the map onto its image.

### 4.3 Which base partners can contain `D`
The real points `Psi(th_n, e^{i th_n})` of `D` lie on any partner containing it. They have direction tending
to `±(a : b)` and bounded offset.
- Line, ellipse, parabola, polynomial graph of degree >= 2, cubic Bezier, power law with `b >= 0`: none has
  a branch at infinity with a finite asymptote unless it is a line [Proof: a polynomially parametrised
  curve has an asymptote only when degenerate], and `D` is not a line.
- Survivors: the **hyperbola and affine images of `y = a x^b`, `b < 0`** (two asymptotic directions).

**Closed cases [Proof + Wolfram].**
- `(r, c) = (1, 0)`: `D` is the cubic `k X Y^2 - k X - Y = 0` [Wolfram: eliminant]. It has a **node at the
  point at infinity `(1:0:0)`**, with tangents `y = ±1`. A nodal Bezier cubic has its node at a finite
  point; the cuspidal cubics `y^2 = x^3`, `y^3 = x^2`, `y^2 x = a^2` have a cusp; a conic has degree 2.
  Affine maps preserve the line at infinity. So no base curve contains `D`.
- **Wolfram samples** of the degree of `D_{r,c}` (`S = (t, sin t)`, `k` generic; implicitisation by
  Groebner elimination):

  | `(r, c)` | `deg D` | pole count `4q+2|p|` | consequence |
  |---|---|---|---|
  | `(1, 0)` | 3 | 6 | `e = 2`; cubic |
  | `(1, c0)`, `cos c0 = 3/5` | 6 | 6 | `e = 1`; sextic |
  | `(2, 0)` | 8 | 8 | `e = 1`; octic |
  | `(3, 0)` | 5 | 10 | `e = 2` |

  None is a conic, so none is a hyperbola. A negative power law `y^q' = a x^p'` has two places at infinity,
  whereas `D` has `2q + 2` places in two directions; for `e = 1` this excludes them. [Heuristic for
  general `(r, c)`: I did not prove `e = 1` in general.] **N-1 stays [Open] for general `(r, c)`.**

### 4.4 G: genus argument [Proof + Wolfram]
For G with `t = th` (`r = 1, c = 0`), section 2.2 gives `K0(th, sin th) = K0(W)`. So `Psi` is birational
onto `D`, and `D` has geometric genus 1. Every base curve is rational (line, conic, graph, power law,
Bezier, ellipse). Hence **no base algebraic partner works** for the natural competitor. For `c != 0` or
`r != 1`, `K0(th, sin(r th + c))` has index <= 2 in `K0(W)` (or its cover), so it might have genus 0:
[Open].

### 4.5 Offset partners (N-2) [Open]
Offsets of rational curves can be rational (parabola offsets are rational, of degree 6), so neither the
genus nor the place-count obstruction passes to offsets. The model curve `D` for P has two parallel
asymptote ends (`y = ±1`), and the offset of a hyperbola also has parallel asymptote pairs. This is the
gap of `sheared-sine-intersections.md` 3e and I could not close it. What would close it: a proof that no
chain `offset ∘ affine ∘ offset ...` of base curves produces `D`; a candidate invariant for P is "a node at
infinity with tangents parallel to the chord of the two asymptote ends".

## 5. Gaps and degenerate cases, stated exactly

5.1 **Transversality** (1.4).
5.2 **Algebraic dependence only.** Competitor data are algebraic over `K0`. Using an earlier transcendental
    construction as data is depth 2 and excluded by the one-step convention.
5.3 **Readout.** Algebraic readout of `th` from `(x, y)`. A readout through a further integral is depth 2.
5.4 **Parallel drifts** (`Delta = 0`: `(a, b) ∥ (a', b')`) in the two-transcendental cases. Then E1 and E2
    give one relation between `(z, w)` and one linear relation between `(t, s)`, and `d = 2` can occur with
    `z, w` algebraically dependent. I did not redo the rigidity computation there. [Open]
5.5 **Offset-type `A_j`** in (Tr, Tr) for P and G (poles of `A_j` at the relevant place). [Open]
5.6 **Analytic section.** To get an analytic section `k -> (t(k), s(k))` I use: the real-analytic solution
    set projects onto an interval, so some stratum is a submersion over a subinterval (Sard). [Proof sketch]

## 6. Where the other approaches fail

1. **Inverse-function monodromy (R3 style).** For P, `th*(k) = kappa^{-1}(k)` with `kappa = tan th sec th
   / th` has infinitely many square-root branch points (critical values of `kappa`). The root function of
   a trig-type ∩ algebraic competitor (a Kepler-like `G(t, sin t, k) = 0`) has infinitely many too. So the
   "finitely many log branch points versus infinitely many" dichotomy that separated the offset-inversion
   family from the tower does **not** apply [Proof of the failure: both sides have the same type of
   singularity].
2. **Root density per turn.** P and X both have 2 roots per turn; so does `Q(t, sin t) = 0` for any
   algebraic `Q`. The asymptotic locations `pi/2 + 2 n pi ∓ 1/sqrt(k th)` (P) and `m pi - 2^{-m pi}/(m pi)`
   (X, from I3) have the shape "root of a trig equation plus algebraic correction". [Heuristic] they cannot
   distinguish; the information is in the whole curve `D`, not in the first asymptotic terms.
3. **Plain Ax counting** settles X (two atoms). For P and G it cannot separate "`D ⊂ T_k` is possible" from
   "`D ⊂ T_k` is drawable"; that is a question about the drawable algebraic curves (section 4), not
   about transcendence.

## 7. Other things noticed

- **Clean reading of the three classes.** P and G are *one-atom* families (the root generates a
  1-dimensional transcendental extension); X is *two-atom*. One-atom families are exactly those the
  sheared-sine machinery can attack with a single algebraic partner. X is not reachable by any algebraic
  partner at all, which is why a proof exists for X.
- **Genus as an invariant.** P has genus 0 (`th = R_k(u)`), the generic conic slice genus 1. The genus-1 family
  survives all rational base partners (4.4). I1's `A = 0` collapse can be read as a genus drop: `Phi`
  becomes linear in `th`, with no discriminant. Worth checking that the aligned class has genus 0.
- **I3 finding 3** (`th sin th = sin(th cos th)`, roots at `m pi`, no non-trivial root for the flipped sign)
  is an "X-minus" family: the exponent atom is replaced by a sine, so the real/imaginary lemma no longer
  separates the atoms. Not analysed.
- **Sheared-sine criterion in this language.** "A sine-type curve meets an algebraic curve uniformly iff the
  curve contains the image of the family's own algebraic curve" is exactly the `tan x = x` statement of
  `sheared-sine-intersections.md`, with `D =` the quartic there.
- **A drawable cubic of the right shape would collapse P.** If any route draws `k x (1 - y^2) = y` (node at
  infinity, parallel asymptotes), P becomes R, and the same cubic gives `x = tan x sec x`. The PPT-curve probe
  of sheared-sine follow-up 1 should look for it.
- **Hypotheses.** The competitor class assumes R3 Theorem 1.1 (closure of T under all spiral-free
  constructors), cited and not re-checked here.
